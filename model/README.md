# 股票排序模型

当前发布：**V259／V247／V321／V348＋事件风险择时**，标注为研究与模拟回放（10月test未通过）。最新配置、训练限制和10月test结果见[releases说明](releases/README.md)；以下旧轮记录按其历史时间理解。

项目为约2100只股票生成每日截面排序，并用排序指标和含费现金账户评估信号。本轮V333–V352共20版及预定对照已完成，当前108个完整模型（4实战发布／100研究／4退役发布）。研究已停止；2026-10-30按用户另行授权完成标准窗组合筛选和Q4实战替换。状态与清理结果见[STATUS](docs/STATUS.md)，恢复研究须用户明确重新授权。

开发迭代先读 [量化模型迭代 Skill](skills/quant-model-iteration/SKILL.md) 和 [本轮记录](docs/iterations.md)。研究以宏观稳定表现、强 IC 与低相关性为目标；小资金榜仍优先展示。每批最多三个待训练方向，完成一版后核对并维护大小资金两榜。

本轮成果与封顶范围见[研究总结](docs/iterations.md#2026-10-30-本轮封顶收尾)，经验和约束见[经验交接](docs/lessons.md)。收尾完成后，旧计划和未训练目录均不授权自动续跑。

## 使用

在项目根目录运行：

```bash
python -B releases/main.py
python -B preparingdata.py --check
python -B -m unittest discover -s tests -v
```

每日入口仅发现 `releases/` 内的四个模型，加载最新完整季度四折权重。按冻结列名、顺序和方向从当前快照取数，再在共同有效股票内按冻结比例融合截尾z分数；生成 `releases/DAILY-YYYYMMDD.md`。

`preparingdata.py` 默认按上游 JSON 生产清单打包，排除仍保留文件的 46 个退库历史因子。生产快照已于2026-11-10重建，包含445个股票因子、50个市场因子及5个标签，九年4,540,905行、写后校验通过；发布模型按各自冻结列清单取数，研究仍读取10-28冻结输入。`cl_tail_cost_asym_5_v1` 已按用户指令永久删除，后续不再使用。共享快照状态、逐列时效及校验范围见 [数据状态](docs/STATUS.md#数据与发布)。

训练和评估命令、输入约束见 [架构与运行](docs/architecture.md)；指标定义见 [评价规范](docs/baseline.md)；发布推演细节见 [发布模型说明](releases/README.md)。

等权组合的换手与容量审计（原始归档已清理）和大资金现金对照（原始归档已清理）已完成；新现金口径只作统一补充，不覆盖原理想主榜。大资金无法成交的股数继续留仓，不能假设发出空仓信号就能次日清空。
