## 1. 这个单元是什么

研究单元（`V16`~`V75`）训练窗止于某季度首日、评价窗锁死在 2025-07-01~2026-06-30，
**对"今天该买什么"没有直接用处**。`best/` 是实战单元：**用上全部可用数据、出当下的选股与下单指令**。

配方照「得分最高的来源」复现 —— R38 那条实测口径：

```
九粒种子（各四折）→ 组内四折打分直接相加 → 组间逐日截面标准差对齐 → 等权平均 → 60 日市场趋势门槛
```

**与研究单元唯一的差别 = 切分口径**：

| | 研究单元 | **`best`（实战）** |
|:--|:--|:--|
| test 窗 | 季度 ∩ 评价窗 | **没有**（用户明确：不跑任何 test 回测） |
| 训练窗 | 止于季度首日 − (h+1) 交易日 | **数据末日退 h+1**（最后一个样本 2026-09-11，其 5d 标签正好落在 2026-09-21） |
| 有效性来源 | test 惩罚 | **valid**：四折轮换的验证块 + 早停（patience 6） |
| 打分窗 | 季度首日 → 数据末日 | 只推演最近 **10** 天（末日那行用于下单） |

★ 特征列一律 **337 列**（`features_old337.json`）。九组必须同列集：`V34/V36/V50/V51/V52` 当年写的
`features='all'` 在当时就是 337 列；照抄到当时的 656 列快照上会静默训成 R37 实测的"新因子臂"
（top1 **−23.65%** vs 对照 **+123.35%**）。`model.py` 里有 `assert len(panel.features) == 337` 专防这一条。
★★ 2026-09-22：这 337 列里有 6 列已被因子侧删除（见 `version.txt` 与上表「待处理」）——
`assert` 现在会**在建面板时就炸**（不是静默），所以必须先定这 6 列怎么办再跑。

## 6. 日常运维

```bash
PY=/autodl-fs/data/miniconda3/bin/python
cd /autodl-fs/data/model/best

$PY ../preparingdata.py --check     # 先对账数据快照（模型只读 trainingdata/）
bash train.sh                       # 36 任务全量（已完成折自动跳过）
$PY analysis.py                     # 只重出票（不重训）—— 每天收盘后跑这条
$PY model.py --split --quarter s3301 # 看生产切分
$PY model.py --quarter s3301 --fold 1 # 单折（调试/续跑）
$PY run.py --jobs 4                 # 降并发
```

★ **数据一变（新交易日进来）必须重训**：`run_id` 含数据块 SHA，指纹不符时 `model.py` 会拒绝复用旧产物。
每天的正确顺序是：`preparingdata.py` 增量 → `train.sh`（会重训全部 36 折）→ `analysis.py`（自动接在 run.py 后）。

## 7. 已知限制（读数字前必须知道）

1. **最新一日打分是样本内的** —— 模型训练时见过 2026-09-21。本单元**不出任何样本外证据**，
   有效性只有 valid 块那一条来源。R38 的 +80.55% 是**评价窗上的历史实测**，
   是"这套配方历史上值多少"，**不是这只模型明天的预期**。
2. **Top1 = 100% 押一只股**（R38 实测 +80.55%、回撤 −16.31%、夏普 1.62）；
   Top5 为 +40.58%、回撤 −14.59%。要分散选 Top5，代价是收益少一半。
3. **2115 只固定池含幸存者偏差**（"至今存续"），绝对值不可当真钱预期读。
4. **训练窗比 R38 的实测口径更长**（R38 是季度截断窗）。同配方、更多数据 ⇒ 期望值**近似迁移**，
   不是逐位复现。
5. 名称来自 `stock_daily.stock_name`，厂商把整段历史改写成了**当前**名称 ⇒ 只能展示，**不可**用于判 ST/风险。
