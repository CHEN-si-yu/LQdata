### ★★ 操作纪律（2026-09-18 事故后新增，见 [VERSIONS.md](VERSIONS.md) §8.7）

1. **重建/覆盖任何非可再生数据之前，先复制一份。** 本次把唯一的 `trainingdata/` 覆盖了，
   而它只有 12 GB、共享盘有 150 GB 空余 —— 纯粹是没做备份的失误。
2. **加了「输出目录」这类参数，就要追到最后一个 `write` 为止。** `--out` 只重定向了
   meta、年分区仍走全局路径 ⇒ 数据与清单分家、零报错、事后才发现。
3. **冻结标记不是万能闸门**：它只拦「从入口进来的重建」，拦不住内部调用路径 ——
   `build_year()` 根本没经过那道闸门。
4. **写含中文的脚本一律用文件，不要 `bash -c` + heredoc。** 本轮为这件事翻了三次车
   （中文被吞成 `?`、CJK 引号与 Python 的 `"` 打架）—— 每次都是几分钟的返工。


### ★★★ 先记住这条方法论（本轮最贵的一课）

**两折的差值不构成结论。** 本库的**折间跨度就有 ±0.03~0.09**（同引擎、同窗、同种子、
只换验证窗位置与模型种子），任何小于它的"改动前后差异"都必须等**四折跑齐**再说。
本轮 V5 就是这么翻的车：折 1/2 时读数像"明确有效"（10d +0.032→+0.070），
折 3/4 进来后全部塌回噪声（|Δ| ≤ 0.016），而且换个实现（V8 的 xgb）直接反号。
⇒ 后续任何"某改动有效"的草稿结论，**先看它有没有超过折间跨度**，没有就写"未观察到效应"。
