# 使用原则

## 数据

- 列名、顺序、方向、标准化语义共同构成输入合同。相同维数不证明输入一致。
- 推演按训练时冻结列名取列并重排；新增列忽略，缺列报错。方向转换只做一次。
- 上游按时间可得的数据才能进入模型。冻结存活股票池与历史因子修订会影响评价解释。
- 历史权重绑定各自输入快照；当前快照适合日常投影推演，不自动保证历史训练可逐位复现。

## 模型与评价

- IC 和现金净收益回答不同问题，必须分别检查。
- 单种子的好收益可能来自训练波动，结论采用种子融合与复本离散度。
- 早停和选轮验证块不能同时充当独立确认集；前向区间不得参与规则选择。
- 不把容量资金档等同于股票市值风格。输入、目标和架构不同，也不自动产生独立风险暴露。
- 当前模型存在共同的小市值偏向，融合时同时查看相关性与账户执行结果。

## 执行

- 账户金额、股票数、调仓周期、缓冲带和门控必须随收益标注；变更后重新比较。
- 小账户中的最低佣金、整手和拒单会改变最优换手；理想组合收益不能替代现金结果。
- 缓冲带和调仓相位会改变持仓路径，单个参数点的收益提高不足以证明信号更强。
- 融合权重先固定再检验，不在测试窗内追逐最高收益点。

## 工程

- 使用 `python -B` 控制字节码缓存；同时检查磁盘容量与 inode。
- 权重恢复包括神经参数、ridge、冻结列和四折完成状态；严格重载后再评分。
- 首先校验实际 cgroup 内存与可用设备，再确定并发；不照搬机器资源数字。
- 新实现需要运行级校验，语法通过不能证明配置或数据合同有效。
- `zscore_win1_99_v1`在标准化后截断到±10，稀疏事件的极值被截断后，逐日均值和标准差可能偏离0/1；不能直接判为口径损坏。快照校验只对此类异常列重放上游原值、方向和完整标准化过程，要求全列含NaN逐值一致；不得整体放宽矩阈值或跳过错误。2026-10-23实例及5项正反例测试见[当日台账](../../check/incremental_20261023/LEDGER.md)，该修正仅改校验，不改标准化、快照或模型权重。
- 当前结果、口径与来源集中维护在 [模型评估](leaderboard.md) 和 [登记表](core_models.json)。

## 本轮经验

用户已于2026-10-25明确停止研究。本文记录已完成工作的经验，不授权继续实验。当前状态以停止记录（原始归档已清理）和会话状态（原始归档已清理）为准。

1. **IC和资金收益要分别看。** 原Top500贪心容量算法可能只给少数股票分配大部分资金。近期V263三组控制的中位有效持仓仅约3.56只；高截面IC仍伴随资金头部亏损。保留原榜，同时用统一L1真实现金补充检查集中度、费用与成交。
2. **小资金高收益不能替代宏观质量。** V282小榜+79.38%，但IC约.02854、近期自身-14.76%；没有据此晋级。重点仍是完整截面、跨季度和统一大资金稳定表现。
3. **低相关和自身质量必须同时成立。** V271、V281等获得较低的部分相关性，但宏观质量不足；V287自身IC改善，最高相关仍约.880。不能只挑一个低相关参照，也不能把强反向依赖当独立。
4. **单组种子增益需要复核。** V263三组IC约.03456/.04053/.03423，样本标准差.00354。模型级成绩先等权原始分数再计算，不能用最好组或指标均值代替。V287目前仅完成原单组；新增两组未训练，已取消，不得登记三组成绩。
5. **验证与成熟历史重训分开。** 旧验证预测必须来自验证前的选择权重；交付权重可在测试前已成熟历史上按冻结轮次重训。教师的训练截止和选轮标签也属于信息边界。冻结岭教师可避免神经教师使用同一验证选轮造成的隐性污染。
6. **新鲜权重并非近期亏损的充分解释。** V263三组Q4补充更新后，近期L1仍亏3.82%；它同时更新权重和验证所选规则，应与原Q3沿用报告分列。30执行日、一日29成熟标签、五日25成熟标签分别记录。
7. **市场概率先与历史先验比较。** 三状态及严格向前校准研究中，校准改善原预测，但测试Brier仍差于先验，收益没有跨窗一致改善。不能用校准拟合改善代替交易增益，也不按近期结果继续扫阈值。
8. **目标仓位不等于成交仓位。** 清仓信号仍可能留下残股；目标权重上限也不保证行情变化后的实际权重一直受限。容量取前日已知成交额，真实部分成交、T+1、费用、现金和末日估值须逐笔对账。不得补写理想清仓或收盘买回。
9. **收益尾部含有信息，不能直接删掉。** 标准期约2%的收益尾部贡献V260/V263/V265约44%/60%/77%的IC协方差；中央股票仍有正向排序。该分组使用未来标签，仅为事后诊断，不能筛交易、决定当日特征归一化池或替换正式IC。完整分解（原始归档已清理）保留并列与缺失口径。
10. **核心修改允许失败，保留机制证据。** 因子筛选、不同表示/网络、DRO、激活、树损失等多数没有稳定增量。SAM的IC降至.01969，20折中9折只选中预热权重，不能宣称这些权重应用了SAM；没有继续半径网格。固定线性锚＋神经修正的V287单组有增量，但还不足以证明稳定优势。
11. **资源和运行保障与模型创新分开。** 按容器实际配额渐增并行，记录全程与高并发均值；queue=0不等于空闲，不用峰值或忙段冒充全程。共享只读面板减少重复加载，fork前CPU张量操作使用单线程。多层目录显式定位项目根；用AST识别末尾入口，避免空格差异。规范审计完成后再跑依赖其分数档案的近期诊断。
12. **证据与交接完整保留。** 输入逐文件归档、全部分数存档、来源指纹、权重重载和独立账本比仅留收益表重要。归档发生在结果之后，不是事前可得性的证明。当前所有结果仍是修订历史与固定股票池上的开发证据、纸面账户；四个发布模型权重没有被研究候选替换。

### 2026-10-28：循环网络的资源预留与无损吞吐

循环网络完整批次须同时记录CUDA allocated与reserved，并检查连续不同股票数批次的缓存碎片；单次探针的allocated不是每折显存上界。以有效日期批次为数学单位，微批按实际日期数加权、累计后仅裁剪一次和更新一次，不能误把优化器更新次数乘上微批数。FP32加法顺序改变须如实记录，早期不一致配方部分权重隔离；自身真实续训仍须完全一致。

CPU验证先排除重复推理。逐日独立模型可在完整日资格池上并行，线程中单独关闭梯度；必须检验原分数和全部选择指标，而非只看速度。GPU/CPU头误差超过原阈值时不放宽阈值，只采用通过的CPU复用方案。共享CUDA输入遵循已有spawn持有、父进程未初始化CUDA、接收端先释放的协议；先验原输入、真实fork生命周期与训练轨迹，再切换驻留位置。每个失败/恢复/优化段分别报告真实资源均值。

### 新增执行与资源经验（2026-10-28）

减少交易笔数不等于降低费用：大资金应核对真实成交额、买卖方向与税费。停止日常权重微调时，必须区分已完成的持仓漂移和仍在容量约束下建仓的未完成订单；直接冻结实际股数会让部分成交永久欠配。状态政策另行冻结、审计，不把结果后变更包装成故障修复。

下一批源码与真实GPU续训预检应在当前训练期间准备；可用槽位按两批实时活动折数协调，固定“另一批没结束就只开一折”会压低长尾利用率。记录整段均值、八折阶段均值和服务器合计范围，保留启动/尾部，不能只报80%～95%的采样峰值。

恢复控制器须按已有guard收据接管正在运行的训练和审计，不截断日志或重复启动。准入要覆盖所有活动阶段，不能只计末组；已有实时总8折预算时，等待上一组queue=0且仅剩2折可能无谓闲置，可在有余量和低负载时提前接入，并冻结调度修订。选择预测的保存合同是排序＋一/五日绝对辅助三列，不能直接拿网络两列forward输出进行错误审计；修复验证器必须保留原失败、源码和不变误差标准。

增量追加新日期可能同时补齐/修订前一交易日少量因子；训练前缀同一不意味着近期全输入同一。10-28三个股息相关列改变10-27行，使旧27与最新28的固定同权重分数不同。冻结预测原件保持，按最新输入重推配对控制再归因，不把输入修订混为模型改进。季度补充均值和中位数等融合都必须先核对每个成员的同输入全截面分数。

训练轮数相同不等于计算预算相同。扩展1648～2037日训练历史会把每轮更新量从最近756日约48次提高到约103～128次；应同时记录独特日期、日期抽样次数、实际AdamW更新数、验证频率与所选轮数。阶段日期统计需要feature coverage，`Panel(load_x=False)`不能调用mask；读取已有只读X缓存即可检查，不必重建因子。

联合分支不能仅凭参数非零宣称互补，也不能凭共享教师后的高原始相关宣称塌缩；同时检查残差函数相关、每个分支自身IC和固定均值，与既有独立三种子对照，不事后挑单分支。梯度投影的优先性只约束原始欧氏梯度，不能直接推广成AdamW实际步长、IC或收益单调改善；只统计最终服务权重之前确实发生的投影，不用后续未选轮次证明应用。

排程准备应在当前批次中段完成后继预检与CPU预热；预检固定轮次不使用验证时，可省略未用的全量Prices构建，正式训练和现金评价仍完整加载。空档必须保留在整机监控，不能通过丢掉等待/尾部采样、相加重叠控制器均值或制造无研究价值任务宣称达标。

CPU预热应优先最近可接棒的一批；提前保留多批全量Prices会使内存准入压低正在运行的GPU并发。远期方向先完成源码与GPU预检，接近前组中段后逐个加载CPU父进程，保持现有总资源保护。取消未开始训练的等待组必须确认零权重/零活动折，保存取消收据和日志，不能混作训练失败或隐藏峰值。

描述性architecture字段也需与最终有效函数核对；从模板继承的旧损失标签可能与实际fit不同。冻结后不要改源码影响签名，保留原描述和SHA，在登记/展示层注明已核对的实现。当前新建仓次日掉榜仍有正标签收益，降低换手不可先验视为滤噪；先重复成本分类和真实入场收益诊断，保留次日分组的事后性质。

共享Prices缓存的键需包含归档指纹、价格根、完整日/股轴、成交额、价格构造/读取AST、字段和热门池设置；不能只按模型号或末日期复用。保存并恢复所有NaN、dtype、数组别名与C/F布局，逐文件hash核验，原子发布、只读mmap。用原现金全输出及真实有价格验证的GPU选轮轨迹对拍，不能只用不读Prices的fixed_epochs证明；wrapper经runpy调用native入口时另检验真实fork的函数序列化。只给尚未开训的单元绑定已验证wrapper，保留冻结单位源码与原价CPU审计。


继承式单文件模型可能有多个同名函数、布局常量和模型类。生成深目录历史复本时，先定位最终有效定义、根目录和原生门禁表达式；旧教师47市场列与主干50列分开检查，不能照抄旧47主干函数后仍比较50列。生成器返回非零时不得继续绑定或推理，运行层修复只针对零权重且已退出的单元，保存失败来源与收据。

训练加速可删除损失未消费的冻结辅助运算，但先检查有效fit与整条模型类AST白名单，完整训练/选轮轨迹对拍包括参数、梯度、优化器、全部RNG和检查点；评价与无梯度推理保持原物理输出。fork父进程在任何权重CPU操作前设torch单线程且不初始化CUDA，再验证真实训练子进程，不只做导入测试。调度问题与模型算法问题分开登记，空档和失败仍计入全监控均值。

新增神经导师或顺序残差必须有同阶段固定导师独用控制；与较弱原线性父版比较的增益不能归功于新增子网络。子网络若标准四个现金季度均弱于自身导师，应停止同族，不能用一个近期窗口救回；导师固定轮数的局部优势也不能直接引出轮数搜索。


### 局部 CPU 初始化也要核对 CUDA RNG

新增零输出残差分支即使包在 `torch.random.fork_rng(devices=[])`，内部 `torch.manual_seed` 仍会设置 CUDA 种子；该上下文只恢复 CPU 状态，不能证明完整随机轨迹未变。V331 的120个初始 CPU 构造虽相同，真实禁用分支三轮 GPU 对拍仍正确失败。改用 `torch.random.default_generator.manual_seed` 仅初始化 CPU 分支，并同时核对120对 CPU/CUDA RNG、禁用分支三轮参数/优化器/曲线/选轮与启用分支真实续训后通过。父进程仍须实际检查 fork 前 CUDA 未初始化；不能靠 CPU 构造输出相同取代真实 GPU 轨迹和原生 fork。失败探针、旧源码与零正式权重单元完整留档，不复用旧通过收据。

冷缓存与文件删除要分清：整机内存包含普通文件缓存与共享内存。确认为已完成、关闭、无映射、五分钟前写入的历史实验文件，可用只读文件描述符 `POSIX_FADV_DONTNEED` 建议内核释放清洁缓存，核对 inode/大小/修改时间未变，保留逐文件台账；不删除权重、不驱逐活跃共享面板、不全局 drop_caches。建议字节量不等于实际驻留量，训练并发也改变总内存，不宣称释放量的因果归属。


### 预检导入不能暗改数值线程环境

多步工具编排必须检查退出码再执行依赖操作；exec返回失败对象不一定抛异常。迁移前先整体校验路径和零正式权重条件，避免移动一半后才断言失败。模型目录保持三源码，探针/恢复/独立账本在统一归档，不将失败标记改成通过来收尾。

不可变模型文件若逐字去重，应逐路径SHA256对拍、原子硬链接替换，记录原inode／mtime与现行共享关系；后续写入沿用原子保存，不原位改共享内容。大批校验可对已关闭的只读文件用POSIX_FADV_DONTNEED控制清洁页缓存，不能让清理I/O推高正在训练的内存压力。环境软件、生产因子／原始数据和个人配置不按临时文件处理。


中断恢复若同时存在多个工作上下文，要先核对真实PID、已有receipt和唯一队列归属，不能各自启动同一个待训复本。本轮两个尾部等待器在任何新折启动前合并为一个；只暂停等待父进程，已被独立守护的原生子任务继续，完成后再替换父队列。复核时必须先读退出码；receipt文件存在不代表成功。一次重载失败即使后续原样复验通过，也保留首个失败和未识别原因，不把不能复现包装为已定位根因。


### 参考模型先验证计算图与状态语义

只读抽取参考实现的最小类，用玩具输入核对梯度、初始化、train/eval状态与随机流，避免直接导入硬编码数据路径、全局线程和训练启动器。当前hqth MoE示例的门控权重经.item()/新Tensor切断任务梯度；专家仍学习，输入变化仍能改变路由，不能把“门控参数不学习”误述为“所有股票路由恒定”。bias更新虽然执行，但加到gate score的语句被注释；eval会改诊断状态，却不因此证明当前输出顺序依赖。未归一topk概率、fresh专家重初始化可能是设计选择，借入已训练教师时则须另外证明函数保留。形状探测不应隐含额外随机前向；真实Dropout与全部RNG轨迹要对拍。

## 组合选型与实战交付

- 最佳有限开发窗组合与最佳单模型不同。先固定自身质量、分数相关、费用／风险、有限搜索范围与目标，再比较组合；列明测试数、未穷举范围与季度相关性，不能把选择后的高收益当成独立确认。
- 股票分数低相关与账户低相关分别核验。均值低于.7不代表每季低于.7；V335／V344在2026Q1达.799。成本压力与删成员诊断报告脆弱性，不继续据此调参。
- 研究成绩属于既定全部种子的原始分数均值时，发布也保留全部种子。四折与种子并非独立市场样本；交付重训保持strict selector及成熟历史边界，不能用新Q4权重回填9月或标准窗。
- 发布清单同时绑定源码、输入列／方向、训练记录、权重和融合方法。先在暂存目录完成CPU重载、正式标准窗融合对拍与真实快照推演，再在发布锁下替换，保留完整旧包与真实信号时间。消费者等待生产者成功退出，不能只看分数缓存路径已出现。

## 头部贪心选型的边界

先冻结榜首范围、质量门槛和信号别名，再逐次最小化与全部池内成员的最大绝对相关性。合并重复排序版本，不能把策略变化当成独立alpha。15人池不代表105对全部低相关：本次从第6步开始最低可达最大相关已超过.7，必须另对最终四人组六对审核。穷举和有限策略比较仍属于重复开发选择；保留全部结果和更低风险的次优收益方案，不将一个净收益目标称为全面最佳。新季度训练会改变依赖，历史低相关需与实战权重短窗观察分列。保留原生单阶段模型的真实训练日期，不为统一口径静默改造成新的两阶段配方。
