# 评价口径与实验判定

本文件规定项目实验的指标、表格解释和版本比较的证据要求。架构及固定文件合同见 [architecture.md](architecture.md)；
逐版改动和结果见 [iterations.md](iterations.md)。

实验单元（`experiments/`，**全市场截面排序**）用逐日**截面** IC / RankIC 与 TopK 组合。


---

# 一、共同条款

## 标准评价窗

标准 test 评价窗按项目数据配置固定为 `2025Q3`、`2025Q4`、`2026Q1`、`2026Q2`，即 2025-07-01 至 2026-06-30，共 242 个交易日。季度切分与每季度 KFold 的 4 折是两个不同维度。

242 日 test 窗适合标准化报告，但对小幅策略差异的辨别能力有限；不能只按一次短窗排名选模型或策略。折、种子和相邻日期也不是相互独立的市场样本。

## 特征集变更的可比性

- 快照特征集变更（新增或删除列）会改变 `meta.json` 的 `columns.features`、`columns.direction` 与 `n_flipped` ⇒ **跨版本比较必须同时记录快照 `built_at` 与股票特征列数**，否则两个"同名指标"可能不是同一份输入。
- 重建用 `--features-from <pinned.json>` 把列集**钉死**，用于新旧快照逐位对拍；`--extra-features <names>` 只允许**显式**纳入「已在发布清单、但尚无注册代码」的已发布因子（口径见 [architecture.md](architecture.md) 的「训练快照」一节）。**不点名即维持旧列集**。
- 老单元的 `RECIPE['snapshot_cutoff']` 与新快照不一致时，`Panel.__init__` 直接 `ValueError('snapshot changed: create a new independent version')` ⇒ **换快照必须新建单元号**；历史单元的 16 折产物与 `final_audit.json` 不得改写、不得重推。
- 特征数不同的单元之间比较指标差异时，不得默认归因于模型配方。

## 执行时序

模型只能使用信号日可获得的输入，信号按明确的下一可执行时点进行交易模拟。未来可执行性标签可用于离线评价，不能作为当日模型输入。日线 OHLC 无法判定同日止盈与止损的先后；相关回测必须说明采用的成交假设。

## 三套口径

所有结果要区分：**理想信号收益、可成交信号收益、现金账户收益**；**毛收益、交易费用与净收益分别列示**。不同口径不可互相替代。

## 比较与晋级证据

**调度与分析注意事项（2026-10-06 用户要求）**：尽量优先完成一个模型的四季度×四折，共16折，再依次推进后续模型；同一模型内可按资源预算并行，后续模型仅补充空闲资源。16折齐全后立即按统一口径回测、权重重载审计、记录结果与更正，再依据完整证据调整新方向。回测与下一模型训练可并行。未齐全的季度/折仅作过程诊断，不得充当完整模型排名、晋级或补种子依据。调度实现和资源注意事项见[architecture.md](architecture.md)的“模型优先的训练与回测顺序”。

**稳定收益与迁移研究注意事项**：重点检验“大资金训练的正确信号可迁移到个人小资金账户”，并检验不同风格模型取长补短；二者作为研究假设，不预设有效。资金档、股票市值风格、主信号指标与含费现金收益分别标注。用统一口径同时记录收益、季度表现、回撤、费用及复本稳定性，并依据反例更正和调整方向。持续研究、资源限制与记录要求见architecture.md相应注意事项。

1. 只改打分、持仓或执行规则时，使用同一权重、同一日期和同一交易假设做逐日配对比较；分别报告毛收益、费用和净收益。
2. 改动训练轨迹、架构、损失、输入特征或数据切分时：**筛选阶段每个候选只训单种子**（2026-10-05 用户明示：逐候选多种子是资源浪费，禁止作为常规做法）；单次训练的领先不能单独作为结论——需要下结论或晋级时，按本节第 6 条的触发门槛补种子复核。
3. 在不同季度或市场区间复核，并使用全部符合无前视条件的前向验证块。干净块要求训练样本结束日早于对应验证块开始日；不得仅凭固定折号认定其无前视。
4. 训练期内可用同日配对的回看数据作相对筛选，但只有多段干净前向区间才能支撑绝对收益水平。筛选通过不等于实战接纳。
5. 参数敏感性必须报：策略层的旋钮（调仓相位、阈值口径、缓冲区宽度等）会显著改变结果，只报一组参数不构成结论。先例（原 research_summary，已退役到 `../history/docs_retired_20261005/`）：同一策略换相位，收益跨度 48.8pp。
6. **种子敏感性研究的触发条件（用户 2026-10-05 定，反浪费）**：种子复核是"留给强模型"的昂贵动作，**不做逐候选的种子研究**。触发门槛（约数）：
   - 已迭代 **≥20 个不同策略/方向**的模型；且
   - 其中出现了新的 **Top-1** 模型；
   - 这时才做 **2~3 个新随机种子**（原种子之外）的测试，报告均值与波动。
   未达门槛的模型：一律按"单复本"标注，不得据单种子结果宣告"最优"或据此晋级。历史批次的多种子产物照旧保留、不追改。

## 模型、种子复本与模型级打分（话术统一，2026-10-05 用户定）

**一个模型 = 一个配方（架构、特征、判据、超参固定）连同它的一组种子。** 同一配方下每个种子是一个
**种子复本**（`experiments/` 的单元目录是复本的留档与复现载体），**不是独立的模型**；复本之间不并列、
不互相排名、不挑单个当作"模型"。

**模型级最终打分 = 种子复本聚合，取均值口径，不取最大值。** 即**打分层面等权融合**：各复本逐日打分
先等权平均，指标（IC / RankIC / top_return / 干净块收益 / 现金净收益等）在融合打分上计算 —— 既往文档
所报"族融合"数字就是本口径。同时**附报复本离散度**（各复本同指标的均值 ± 标准差）说明种子波动；
单复本数字只在过程文档中作诊断，不得作为模型成绩引用。

不用 max 的理由（实测先例，与上节第 2 条同源）：单种子最好值是把方差当水平 —— 同配方 4 复本的干净块
相差 ±7pp/年、242 日净收益 ±11.9pp；V5 在评价窗排第 1，到有功效的台子上掉到第 21/25。
历史文档（wave1–3、STATUS 等）的旧措辞不回溯改写，以本节为准。

配套约定：

- **补种子 = 给同一模型加复本**（如 4 → 8），不是新模型；改配方（架构/特征/判据/超参）= 新模型。
  **补种子的时机与门槛见「比较与晋级证据」第 6 条**（只给达到触发条件的强模型补；不做逐候选的种子研究）。
- 报数格式：`<配方名>（N 种子）` + 聚合值（± 复本波动）。例：「`dual_leg_tradable`（4 种子）干净块
  65.73%/年；复本 40.24 ± 7.05」。
- 此前文档中的"族 / 家族"与"模型"同义；今后统一说"模型"。

# 二、`experiments/`：全市场截面排序

## 标准评价配置

理想信号指标采用按打分排序构造的 TopK 组合：最多 500 只股票、资金规模 15 亿元，逐日记录标签收益；不扣交易费用，也不使用停牌、涨跌停或可成交性掩码。成交额缺失或为零的股票不分配仓位；标签缺失按 0 计，RankIC 只使用成对有效值。

该组合衡量排序信号，不代表可成交收益。现金账户结果另按配置模拟费用、滑点、整手、T+1、容量、拒单和现金约束；两种口径必须分开报告。

## 指标定义

`final_audit.json` 的总计字段是逐版总表的数字来源；`picks.md` 提供季度分项以及 test 和 valid 两张表。

| 指标 | 定义 |
| --- | --- |
| `IC_1d` / `IC_5d` | 每日横截面打分与相应期限收益标签的 Pearson 相关，按日等权平均 |
| `ICIR` | 日 IC 均值除以日 IC 标准差，不年化 |
| `top_return` | 理想 TopK 组合的日收益均值，单位为百分比，不是累计收益 |
| `top_return_stability` | 日收益均值除以日收益标准差，不年化 |
| `RankIC_1d` / `RankIC_5d` | 每日横截面打分与对应期限标签的 Spearman 相关，按日等权平均，仅使用成对有效值 |
| `total_return` | 将区间逐日收益复利得到的总收益：`∏(1+r/100)-1`；`picks.md` 的 `收益(%)` 对应此项 |

Pearson IC、Spearman RankIC 和不同期限的标签相关不可互换。所有报告均注明指标名和期限，不以未注明口径的“IC”代替具体字段。

## `picks.md` 的两张表

- **test 表**：四个 test 季度的分项及整窗总计。季度收益各自复利；总计收益按 242 个交易日整体复利。
- **valid 表**：各折 best epoch 对应的 `complete.json.best_validation`。季度为 4 折均值，总计为 16 折均值；收益基于验证集日收益均值按 5 日区间代理复利，因此是训练侧参照，不可与 test 总收益相减解释为衰减。
- 两表各包含 `收益(%)`、`IC_1d`、`IC_5d`、`RankIC_1d`、`RankIC_5d`。表格后再列每日选股结果，表格之间不插入说明文字。

## 结果来源

- 指标总计：单元 `model_info/final_audit.json` 的 `metrics_total`。
- test、valid 季度表和近期排名：单元 `model_pred/picks.md`。
- 现金账户实现值：单元 `model_info/two_strategy_validation.json`。
- 逐版摘要：本项目 `iterations.md`；记录权重是新训还是复用，以及对应来源单元。

# 三、回测表达统一（对齐 min_test，2026-10-05 用户定）

模型侧所有回测数字，**统一用 min_test 的表达**（与公司同名管线逐字同源；参考实现
`HQTH/hqth_min_test.py` 的 `get_ret_ic / get_metrics`）。**不追溯重算**：已训练完成的单元与产物
照旧保留（用户 2026-10-05 定），本节适用于**今后**产出的报告、文档与评估。

## 标准表达（唯一）

- **四指标**：`IC`（日度截面 Pearson：打分 vs `label_ret_1d`，日度等权平均）、
  `ICIR`（IC 均值/标准差，**不年化**）、`top_return`（组合日收益均值，单位 %/日）、
  `top_return_stability`（其均值/标准差）。
- **组合模拟（top_return 的载体）**：日度调仓；取打分最高 `topn` 只；名义资金 `money`；
  单票持仓 ≤ 当日 `amount`（成交额）；**不扣费用**、不加停牌/涨跌停掩码；标签缺失按 0。
  **默认 `topn=500, money=1.5e9`（=公司口径）**；使用其它组合规模（如 `topn=5, money=1e7`）
  时**参数必须随数字一起标注**，不得省略。
- **季度表达**：`季度平均收益(%)` + `季度平均IC` 的季度表（评估窗的四个/八个季度）。
- 打分统一先做逐日截面 z-score 再评估（单调变换，不影响 IC 与排序类指标，仅为口径一致）。

## 对齐映射（存量各表达 → 状态）

## 引用规则

1. 报四指标即默认 min_test 表达；引用任何辅助表达必须**标注口径名**（如"现金账户（10 万、含费）"）。
2. `topn/money` 非默认时参数随数字写（例：`top5/1000万`）；同一表中不同参数不得混列。
3. 存量数字的引用方式：单元 → `final_audit.json` 四指标 + `picks.md` 季度表；HQTH/BEST → `HQTH/RESULTS.md`、
   `HQTH/BEST_RESULTS.md`。**均不重算**；历史产物不追改。
