# 评价规范

## 样本与输入

标准历史评价窗为 **2025-07-01 至 2026-06-30**，对应四季度×每季度四折。当前10-27/10-28冻结快照为242个信号日；历史快照的日历与有效天数按各自冻结报告保留。季度和折是不同维度，折、种子与相邻日期不视为独立市场样本。

每条成绩注明评价窗、输入快照时间和特征数。相同日期但不同快照的成绩分区阅读，不能把差异直接归因于配方。已完成模型的结果与快照登记在 [core_models.json](core_models.json)。

股票池和因子历史可能包含存活样本选择与回顾偏差；历史收益不用于直接估计未来可实现水平。已参与方向选择的窗口属于筛选证据。

研究目标以宏观稳定表现、稳定收益及有竞争力的 IC/ICIR 为主；榜单展示仍优先小资金主榜。小账户少数股票的极端收益不能作为主要训练或选轮目标。研究流程、相关性低于0.7的优选目标与双榜维护见 [模型迭代 Skill](../skills/quant-model-iteration/SKILL.md)。

## 大资金体系：信号次榜

| 指标 | 定义 |
|---|---|
| IC / IC_1d | 每日截面分数与 `label_ret_1d` 的 Pearson 相关，按日等权平均 |
| ICIR | 日 IC 均值/标准差，不年化 |
| top_return | 理想组合日收益均值，单位 `%/日` |
| top_return_stability | 日收益均值/标准差，不年化 |
| IC_5d | 每日分数与五日收益标签的 Pearson 相关均值 |
| RankIC_1d / RankIC_5d | 分数与相应期限标签的每日 Spearman 相关均值 |
| total_return | 逐日收益复利后的区间收益，单位 `%` |

标准四指标为 **IC、ICIR、top_return、top_return_stability**。默认组合为 `topn=500, money=1500000000`：按分数排序、成交额容量限制、日度构造，不扣费、不添加可成交性掩码。Pearson IC 的缺失标签补 0，RankIC 使用成对有效样本。分数可先按日截面标准化，单调变换不改变排序。

采用其他资金或股票数时参数随数字标注；Pearson IC、Spearman RankIC 和不同收益期限不能互换。

## 小资金体系：优先主榜

理想信号收益、可成交信号收益、现金账户收益分别报告。现金回测考虑手续费、滑点、整手、T+1、容量与拒单，报告净收益、回撤、季度收益和费用；毛收益与费用应能拆账。

统一对照口径与 releases 账户执行规则一致：**10 万元、最多持仓 5 只、每日检查、band40、成本门控关闭**。已有持仓在前 40 内保留，出界后按可成交条件补位。逐模型使用各自冻结分数回测；当前实际发布信号为V322／V259／V282／V335的截尾z分数等权融合，单模型结果不代表组合实绩。

新研究版本允许采用自身策略，同时报告同分数的上述统一基线。常规换仓/风控仅在下一交易日开盘；做T的明确例外是开盘卖隔夜底仓、当天尾盘按收盘价买回，决策事先固定并按真实拒单、现金与T+1约束执行。不使用不可得的当日上午数据。

小资金榜按**整窗含费净收益降序**排列；并列时依次比较较小回撤、较低手续费、模型编号。净收益非年化；账户 Sharpe 为日收益均值/标准差×√242。四季度账户连续运行，按信号季度归属下一可执行日与清仓尾部，四段复利等于整窗收益。

两套体系独立排序，优先查看小资金体系。`small_capital` 为主榜结果，`metrics_total` 为大资金信号结果。登记表 `cash_auxiliary` 的每五日检查、门控开启结果仅作对照，不与主榜混排。信号窗、交易尾部及各项参数均随结果标注。

信号只用当时可获得的输入，在明确的下一可执行时点交易。离线可成交性标签不作为当日模型输入。日线数据无法确定同日止盈、止损的先后，需要明确成交假设。

## 复本与模型级成绩

**模型=固定配方及其种子复本集合。** 补种子不增加模型数；修改架构、特征、训练目标或选轮准则才构成新配方。

模型级打分先将种子复本分数等权平均，再计算指标；另附各复本同指标的均值与标准差。不能选最好的种子充当模型水平，也不能用指标的均值替代融合分数上的指标。

候选筛选默认单种子，必须标明筛选状态。种子复核留给强模型：在至少约 20 个不同方向中出现新的领先模型时，才补 2–3 个新种子复核；不对每个候选常规补种子。

## 有效比较

1. 策略变化用同一权重、日期与成交假设做逐日配对比较。
2. 训练配方变化先完成全部季度与折，再统一评价；部分折不进入完整排名。
3. 训练与验证按最长标签期隔离；训练结束日早于评价块开始日。用于早停、选轮的验证块仍有选择偏差。
4. 结合季度、前向区间、费用、回撤与种子波动，不凭一个短窗宣布胜出。
5. 调仓相位、缓冲带、门控和融合权重存在路径敏感性。预先固定规则，并报告反例与敏感性。
6. 信号低相关只说明分数有差异；组合改善还需在统一现金引擎及未参与选择的样本上验证。

研究模型的逐季 test 与训练 valid 分开解释：`picks.md` 的 test 收益是测试日收益复利；valid 是训练侧选轮参照，不能相减解释为样本外衰减。发布权重的 live 核验与匹配配方的历史评估也分别记录。
