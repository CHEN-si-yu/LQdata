# 评价口径与实验判定

本文件规定项目两层的实验指标、表格解释和版本比较的证据要求。架构及固定文件合同见 [architecture.md](architecture.md)；
逐版改动和结果：主族见 [iterations.md](iterations.md)，动作层见 [iterations2.md](iterations2.md)。

★ **两层口径不可互相引用**：

- `experiments/`（**全市场截面排序**）用逐日**截面** IC / RankIC 与 TopK 组合；
- `experiments2/`：新单元在固定小股票池内训练排序/打分模型并优化组合策略；信号指标按池子第一主成分占比选择，账户按组合口径评价。V1–V50 保留原有逐票时序择时口径。

# 一、共同条款（两层都适用）

## 标准评价窗

标准 test 评价窗按项目数据配置固定为 `2025Q3`、`2025Q4`、`2026Q1`、`2026Q2`，即 2025-07-01 至 2026-06-30，共 242 个交易日。季度切分与每季度 KFold 的 4 折是两个不同维度。两层使用同一个窗，因此两层的曲线可以放在同一根时间轴上对照。

242 日 test 窗适合标准化报告，但对小幅策略差异的辨别能力有限；不能只按一次短窗排名选模型或策略。折、种子和相邻日期也不是相互独立的市场样本。

## 执行时序

模型只能使用信号日可获得的输入，信号按明确的下一可执行时点进行交易模拟。未来可执行性标签可用于离线评价，不能作为当日模型输入。日线 OHLC 无法判定同日止盈与止损的先后；相关回测必须说明采用的成交假设。

## 三套口径

所有结果要区分：**理想信号收益、可成交信号收益、现金账户收益**；**毛收益、交易费用与净收益分别列示**。不同口径不可互相替代。

## 比较与晋级证据

1. 只改打分、持仓或执行规则时，使用同一权重、同一日期和同一交易假设做逐日配对比较；分别报告毛收益、费用和净收益。
2. 改动训练轨迹、架构、损失、输入特征或数据切分时，至少比较 4 个种子，报告均值和种子间波动；单次训练的领先不能单独作为结论。
3. 在不同季度或市场区间复核，并使用全部符合无前视条件的前向验证块。干净块要求训练样本结束日早于对应验证块开始日；不得仅凭固定折号认定其无前视。
4. 训练期内可用同日配对的回看数据作相对筛选，但只有多段干净前向区间才能支撑绝对收益水平。筛选通过不等于实战接纳。
5. 参数敏感性必须报：策略层的旋钮（调仓相位、阈值口径、缓冲区宽度等）会显著改变结果，只报一组参数不构成结论。先例见 [research_summary.md](research_summary.md) 的"相位方差"（同一策略换相位，收益跨度 48.8pp）。

# 二、`experiments/`：全市场截面排序

## 标准评价配置

理想信号指标采用按打分排序构造的 TopK 组合：最多 500 只股票、资金规模 15 亿元，逐日记录标签收益；不扣交易费用，也不使用停牌、涨跌停或可成交性掩码。成交额缺失或为零的股票不分配仓位；标签缺失按 0 计，RankIC 只使用成对有效值。

该组合衡量排序信号，不代表可成交收益。现金账户结果另按配置模拟费用、滑点、整手、T+1、容量、拒单和现金约束；两种口径必须分开报告。

## 指标定义

`final_audit.json` 的总计字段是逐版总表的数字来源；`picks.md` 提供季度分项以及 test 和 valid 两张表。

| 指标 | 定义 |
| --- | --- |
| `IC_1d` / `IC_5d` | 每日横截面打分与相应期限收益标签的 Pearson 相关，按日等权平均 |
| `ICIR` | 日 IC 均值除以日 IC 标准差，不年化 |
| `top_return` | 理想 TopK 组合的日收益均值，单位为百分比，不是累计收益 |
| `top_return_stability` | 日收益均值除以日收益标准差，不年化 |
| `RankIC_1d` / `RankIC_5d` | 每日横截面打分与对应期限标签的 Spearman 相关，按日等权平均，仅使用成对有效值 |
| `total_return` | 将区间逐日收益复利得到的总收益：`∏(1+r/100)-1`；`picks.md` 的 `收益(%)` 对应此项 |

Pearson IC、Spearman RankIC 和不同期限的标签相关不可互换。所有报告均注明指标名和期限，不以未注明口径的“IC”代替具体字段。

## `picks.md` 的两张表

- **test 表**：四个 test 季度的分项及整窗总计。季度收益各自复利；总计收益按 242 个交易日整体复利。
- **valid 表**：各折 best epoch 对应的 `complete.json.best_validation`。季度为 4 折均值，总计为 16 折均值；收益基于验证集日收益均值按 5 日区间代理复利，因此是训练侧参照，不可与 test 总收益相减解释为衰减。
- 两表各包含 `收益(%)`、`IC_1d`、`IC_5d`、`RankIC_1d`、`RankIC_5d`。表格后再列每日选股结果，表格之间不插入说明文字。

## 结果来源

- 指标总计：单元 `model_info/final_audit.json` 的 `metrics_total`。
- test、valid 季度表和近期排名：单元 `model_pred/picks.md`。
- 现金账户实现值：单元 `model_info/two_strategy_validation.json`。
- 逐版摘要：本项目 `iterations.md`；记录权重是新训还是复用，以及对应来源单元。

# 三、`experiments2/`：固定小行业池训练排序与组合策略

本节新规范适用于 V51 及之后的新单元。V1–V50 的股票池、实现和历史指标保持不变；不得据新规范重算或改写旧单元结论，历史口径见本节末尾。

## 股票池冻结与体检

- 在观察任何策略收益前，按 RECIPE 的确定性规则选定单一行业和股票池，并冻结行业层级/代码、成分名单、快照日期及选池规则。不得按测试窗收益挑行业、股票或池子大小；逐版记录选池来源及预先冻结事实。
- 报告池内两两收益相关均值、第一主成分解释方差占比（PC1）、价格口径和体检区间。
- PC1 ≤ 0.6：可将每日截面 IC、RankIC 和 TopK 作为主要信号指标。
- PC1 > 0.8：横截面 IC / RankIC 在该池没有意义，不得作为主要信号结论；必须以时序 IC 和相对同池等权基准的超额为主，并在报告中明确说明。
- 0.6 < PC1 ≤ 0.8：同时报告截面和时序信号指标；主要结论依据同池等权超额及干净验证块复现。

## 模型训练与策略选择

- 沿用 experiments 的因子和市场因子面板、标签定义、训练/验证切分、purge、早停及 epoch bagging；标签为 label_ret_hd[T] = adj_open[T+1+h] / adj_open[T+1] - 1，唯一的样本域变化是仅保留冻结池内样本。
- 使用四个标准季度、每季四折及四个种子。训练配方改动至少跑四个种子并报告均值和种子间波动；四季、四折、四种子结果进入审计。
- TopK、目标仓位、阈值、缓冲区、调仓周期等策略候选及搜索范围预先写入 RECIPE。参数只能依据训练期无前视干净验证块选择；训练样本结束日必须早于验证块开始日。
- 242 日 test 窗（2025-07-01 至 2026-06-30）只用于冻结方案后的展示，不是取舍依据；不得用它挑股票池、参数或种子。结论须检查多段干净前向区间和种子间分布。

## 评价口径

所有结果分开标注 **理想信号、可成交信号、现金账户** 三种口径；三种结果不可互相替代。

- 组合现金账户使用 RECIPE 中的账户资金；池内股票共用资金与现金，不拆成互不流动的单股账户。T 日收盘出信号，T+1 开盘执行。
- 每个区间同时报告**毛收益、费用、净收益**、平均敞口、敞口匹配 alpha、最大回撤、成交笔数、blocked_entries 和 blocked_exits。敞口匹配 alpha = 策略净收益 − 平均敞口 × 同池等权买入持有净收益。
- 费用按仓位/目标敞口档位分档，计入最低佣金、滑点和其他交易费；成交、拒单均按组合账户统计。
- 报四个种子的逐种子结果、均值和种子间波动；对仓位档位、阈值、缓冲宽度、调仓周期、TopK 报参数敏感性。只报单组参数不能构成结论。
- 同窗同日配对比较同池等权买入持有、四大行 60 日动量 Top1/Top2、四股等权。均列毛收益、费用和净收益；不直接比较不同时窗或账户口径。

### V1–V50 历史口径（仅用于解释既有单元）

#### 任务与交付物

本层只研究**极少数股票**的仓位决策：在一小组票（股票池由单元配置指定，模板单元取四大银行）上，模型对每只票给出打分，并据此决定**这只票下一交易日该持有多少仓位**。

交付物是**每只票的目标仓位**（档位由单元配置决定），动作 = 目标仓位 − 当前仓位，读作「加仓 / 持有 / 减仓 / 清仓」。它与主族的区别不是"参数不同"，是**任务不同**：

| | `experiments/` | `experiments2/` |
| --- | --- | --- |
| 输出 | 全市场每只票一个排序分 | 池内每只票一个**目标仓位** |
| 决策 | 买排名前 N 的票 | 这只票**明天加仓还是清仓** |
| 标签用法 | 截面排名（IC / RankIC 有意义） | 该股**自己的绝对收益**（截面 IC 无意义） |
| 回测 | TopK 组合 | **每只票各自的仓位账户** |
| 基准 | `top1_1d` | **同窗买入持有** |

#### 标准评价配置

- **评价窗与切分**：与主族完全相同（见「共同条款」），季度前 purge 最长标签期 + 1 个交易日，训练集把验证块整段挖掉，测试窗严格样本外。
- **账户**：`RECIPE['account_money']`（默认 **10 万元**）是唯一真源，均分到池内每只票、各自独立记账，**现金不跨票流动**（既不互相补贴，也让逐票归因直接可得）。
- **打分 → 仓位**的规则（用什么档位、阈值怎么定、是否设滞回）由单元实现决定，写在单元 `RECIPE` 与实现里；**评价只要求把结果按下面的指标与三口径报出来**。

#### 指标定义

| 指标 | 定义 |
| --- | --- |
| `ts_ic` | 每只票 `score` 与其**自己的**未来收益标签的时序相关（Pearson / Spearman），再对票等权平均。报告必须同时给 `days` 与标准误 `1/√(n−3)`。 |
| `action_hit_rate` | 加仓信号后 h 日收益为正的比例、清仓信号后为负的比例，**必须与同一窗口的基率并列**（无条件的 `P(y>0)` / `P(y<0)`）。 |
| `return_value` | 账户**净**收益（含费用、滑点、整手、T+1、拒单），`∏(1+r)−1`。 |
| `gross_return` / `cost_drag` | **毛**收益（同一套仓位路径、零费用零滑点）与成本拖累（毛 − 净）。三者必须同时给出：该层的结论高度依赖费用，缺毛收益就分不清"模型不行"还是"费用吃掉了"。 |
| `annualized` | 按 242 交易日折算的年化净收益。 |
| `max_drawdown` | 账户权益的最大回撤。 |
| `total_fees` / `trades` | 总费用与成交笔数。**费用要分档看**（见下条）。 |
| `avg_exposure` | 平均持仓市值 / 权益。数值取决于策略的平均仓位，必须落盘 —— 它决定了"与基准比收益"是否有意义。 |
| `alpha_vs_buy_hold` | **敞口匹配**后的超额：`策略收益 − avg_exposure × 买入持有收益`。 |
| `blocked_entries` / `blocked_exits` | 因涨停/跌停/停牌/无量而**无法成交**的买/卖次数（不含"现金不够买一手"这类非拒单情形）。 |

**截面 IC / RankIC / TopK 日收益在该层没有意义**，不得从主族照搬：池内通常只有几只票，且彼此高度相关（模板池内两两相关 0.80~0.88），每天的"截面"几乎没有独立信息。该层的信号指标是**时序** IC 与动作命中率。

#### 执行时序与账户假设

- **时序**：T 日收盘出信号 → **T+1 开盘**执行（与快照标签口径一致：`label_ret_hd[T] = adj_open[T+1+h] / adj_open[T+1] − 1`）。
- **整手**：全部按 100 股整数倍；目标股数按**该票账户的当前权益**计算（不是初始名义），因此分红折算的经济股数不会被慢慢稀释，也不会有整手零头永久沉淀。
- **费用**：`fees()` = 佣金 `max(名义×0.00025, 5)` + 过户 0.001% + 卖出印花 0.05%，另有单边 3bp 滑点。★ **佣金下限**在单笔名义 < 2 万元时生效：小账户分到每只票的金额本来就不大，仓位越低单笔越小、费率越高（实测半仓档的单边费率可达满仓的 1.5 倍以上）⇒ 费用必须**分档**报。
- **拒单**：开盘涨停/跌停/停牌/无量时不可买/不可卖；被拒的**差额顺延到下一个开盘**（目标不变、下一日自然重试），计数落 `blocked_entries` / `blocked_exits`。模板池在快照全期从未触发过拒单 —— 所以计数必须落盘，否则"逻辑没接上"与"确实没发生过"长得一模一样。
- **公司行为**：持仓股数按 `adj[d]/adj[d−1]` 折算，假设分红立即再投资（近似，与主族同口径）。
- **末尾**：最后一个可执行日按目标 0 清仓；卖不掉的按市值计入权益，**不强平**。

#### 本层附加的判定条款

1. 只改策略或执行规则时，用**同一份权重、同一批日期**做逐日配对比较，分别报毛收益、费用、净收益与敞口。
2. 参数敏感性必须报：仓位档位、阈值口径、缓冲区一类旋钮会显著改变结果，**只报一组参数的结果不构成结论**（同「共同条款」第 5 条）。
3. **可证伪判据（该层存在的意义）**：若动作策略在**敞口匹配后**的净收益跑不赢同窗买入持有，或在无前视干净块上不能稳定复现，则该层没有价值 —— 应当如实写"否"，而不是换指标继续找理由。

#### 与生俱来的局限（写在前面，避免误读）

- **池小 = 样本少**。242 天评价窗对策略层没有统计功效（`|ρ|=0.1` 时 SE≈0.064），单窗收益与名次**不构成结论**。
- **池内高度相关** ⇒ 池内各票的收益绝大部分由共同因子驱动（模板池第一主成分约占 87%），因此该层的结果主要是**这批票共同行情的时机**，而不是票与票之间的差别；报告里不得把它写成"选出了更好的那只"。
- **费用占比高**。小额账户 + 频繁调仓 ⇒ 往返成本是决定性的；任何"多动一次"的改动都必须先过费用这一关。
