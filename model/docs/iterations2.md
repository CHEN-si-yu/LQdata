# 实验记录（experiments2 · 动作策略）

一行一节纪录一个实验（每个 `Vx/` 独立单元），登记该版**动作策略的最终结果**。
**指标口径、计算窗与记录要求见 [baseline.md](baseline.md) 中 experiments2 一节。**

★ 本文件与主族的 [iterations.md](iterations.md) **分开，不混表**：两层的号段（`V1`…）各自
独立，裸编号会歧义 ⇒ **本文件与其它文档引用本层单元时一律写全路径**（`experiments2/V1`）。

数字取自：

- **账户净收益 / 回撤 / 费用 / 敞口 / 敞口匹配 alpha** → 该单元 `model_info/final_audit.json`
- **逐日动作、时序 IC、命中率与基率** → 该单元 `model_pred/actions.md`
- **账户实现值与口径自检** → 该单元 `model_info/action_validation.json`

**数值由脚本产出，本文件的叙述由 Agent 写**；不要手改数值，脚本重跑后按新数字更新本节。

每版摘要固定三行：改动、结果、结论；结果行同时注明权重来源（新训、复用哪版或未训练）。
起点与复用规则见 [architecture.md](architecture.md#单元继承与训练)。

# ★★★ 排行榜（experiments2 全部版本一览）

**排序口径 = 242 天 test 评价窗的账户净收益（含费）**，但**先读这三条，否则一定会误读**：

1. 三档分位策略的平均敞口约 0.5，与买入持有的 1.0 **不可直接比收益** ⇒ 判优劣看
   **敞口匹配 alpha**（`策略收益 − 敞口 × 买入持有收益`），不是看净收益那一列。
2. 242 天窗对策略层没有统计功效（`|ρ|=0.1` 时 SE≈0.064）⇒ **名次 ≠ 优劣**。
3. 本线是**板块择时**，不是池内选股（池内两两相关 0.80~0.88、第一主成分 87.3%）。

## experiments2/V1（四大银行仓位动作）· 2026-09-27

- 改动：使用最新快照（截至 2026-09-24）中的 484 个个股因子与 122 个市场因子；LightGBM Huber
  双期限（1d/5d）集成，4 个随机种子；输出逐票阈值动作并按 T 收盘、T+1 开盘执行。
- 结果：新训权重；242 个交易日（2025-07 至 2026-06）净收益 **-6.997%**、年化 **-6.997%**、
  平均敞口 **74.3%**、敞口匹配 alpha **-8.202%**、最大回撤 **-14.59%**、费用 **1,335 元**、
  162 笔成交、1d 时序 IC **-0.037**、加仓命中率 **43.2%**。四个种子均亏损，种子净收益均值
  **-6.93%**，0/4 个种子取得正 alpha；同期买入持有净收益 **+1.622%**。数据价格对拍、
  权重重载、固定目录布局和账户执行不变量审计均通过。
- 结论：模型动作在正式评价窗没有带来提升，9 组同权重阈值敏感性也均为负 alpha；当前版不作为有效策略。
