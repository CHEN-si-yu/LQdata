## 运行与仓位

```bash
python -B releases/main.py --days 16 --out releases/DAILY-20261029.md
python -B releases/strategy.py --asof 2026-10-29
```

日期文件名不控制输入日期；推演读取当前快照末日。第二条命令输出该信号日对应下一开盘的风险预算。日报中已显示风险概率、目标仓位和目标股数。Top10只是排序候选，形成实际订单仍需要持仓账本；工具不连接券商、不自动下单。

每日操作核对须读取当前`release_config.json`和正式日报的`signal_archive`全截面分数。旧`dsh_scratch/releases_daily_helpers/capture_scores.py`调用`predict_window`时未传当前融合配置，会落入默认`rank_mean`，不能据其融合排名制定当前发布包订单；`ops_tomorrow.py`也仅实现满仓B40，不处理事件风险仓位。2026-10-30日更已直接从正式归档按`zscore_clip3`重建持仓名次，并优先应用`strategy.py`预算，未修改生产代码。源数据晚到时，快照后检通过不等于上游完整性通过；日报须标明缺口，补齐后刷新因子、快照和正式推演。

10万元、最多5只、B40。常规买卖均下一交易日09:30；保留最低佣金、税费、0.03%单边滑点、整手、T+1、容量、停牌和涨跌停。旧持仓在前40名内可保留，但风险规则要求的降仓／清仓优先。

- 沪深300日收益≤-3.5%、跌停比例≥8%或事件风险概率≥35%：目标空仓。
- 非空仓状态下概率≥20%：目标40%，原生目标股数为2；其余目标100%、最多5只。
- 空仓后恢复：连续两个信号日概率<15%且站上20日均线的股票占比≥45%，下一开盘恢复100%；不满足则继续空仓。
- 涨跌停或停牌可能导致目标仓位不能成交；残余持仓和损益如实保留，40%不保证实际持仓恒为两只。

风险概率复用冻结的V260原生Q4四折模型，训练最晚8月31日，输入47列；预测事件是次日股票池均值跌幅至少2%或五日至少4%。权重已随包保存于strategy_data；strategy.py内固定生产执行函数与研究原生引擎逐值对拍。默认风险状态从10月1日现金账户初始化；跨季度需更新季度权重，不自动沿用到2027年。
