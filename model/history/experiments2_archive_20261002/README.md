## 这层是什么

`experiments2/` 曾与 `experiments/` 并列为两层实验层（任务不同、互不调用、只共享 `trainingdata/`）：
在预先冻结的小股票池（模板池为四大银行）内训练排序/打分模型，判断每只票该**加仓还是清仓** ——
评价用该股自己的**时序 IC** 与**按票独立的仓位账户**，基准为同窗买入持有。
与主族的区别不是参数，是任务：输出"目标仓位"而不是"全市场排序"。
