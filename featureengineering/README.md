## 生产运行

```bash
python main.py                              # 日更；首次补历史
python main.py list                         # 注册与覆盖
python main.py run momentum_20 roe_ttm       # 指定因子，含父依赖
python main.py run --dry-run                 # 查看计划
python main.py rebuild --jobs 1             # 强制重算
python main.py rebuild --resume --jobs 1    # 全量中断后恢复
```

已有覆盖和完整分区自动跳过，新因子补历史，标签回算未成熟尾部。公式变更须显式重建，上游历史修订使用限定日期的 `--refresh`。含R16ML1的CUDA跨年运行或重算使用 `--jobs 1`；无CUDA自动回退CPU。**筹码已采用按月构建的共享年度摘要，旧三量九年逐格等价；新增三族可单列 `python main.py run --group chip_green_shape chip_green_close chip_green_temporal --jobs 4`。本轮8进程采样charged峰值52.39GiB，按实际资源选并发。**

股票因子和标签位于 `data/factors/<name>/year=YYYY/data.parquet`，市场因子位于 `data/market_factors/`，断点位于 `state/`。股票轴固定2115只，缺测保留NaN，标签rank为空。生产直接写年度Parquet，不执行研究审核、评估或旧发布。

`conf/production.json` 当前列出全部500项生产对象（注册SHA256 `c2dafa906794a293d363d6040a69b1c590b426ff6b83707871ac6c9949b1d8e9`），其中149项已有内置注册、351项通过显式定义补充；实现及公共函数位于 `factors/registered/`。2026-10-27按用户要求整理旧挖掘产物：清理已结束的work研究目录、旧交付包/审计副本及Python/Jupyter临时文件。保留全部生产代码、配置、数据和必要缓存、断点、日志/锁、文档与参考资料；研究结论和失败机制保留于现有文档，不另留研究备份。未来挖掘按[统一手册](doc/05_因子开发套路与模板.md)重新启动。
