# 经典质量与风险因子

财务质量、盈利能力和低Beta组合提供不同的研究视角。财务信息可以在披露后映射到每日；日频组合收益仍需与信号更新时间分开。这些来源主要研究美国或国际市场，A股适用性属于后续迁移判断。

| 机制 | 来源支持的内容 | 需进一步核对 |
| --- | --- | --- |
| F Score | 九项财务信号形成综合评分 | 年报口径、披露日、评分边界和A股样本 |
| 毛利润资产比 | 毛利润相对资产的盈利能力概念 | 分母时点、金融股口径、缺失与过滤 |
| Quality Minus Junk | 质量与低质量公司的组合研究 | 完整评分规范和A股组合构建 |
| Betting Against Beta | 调整低高Beta资产形成组合，提供日收益数据 | Beta估计、杠杆、做空和执行条件 |

F Score分项在记录中归为评分组件和参数变体，避免把九项条件当作九个已验证的独立Alpha。财务指标是慢更新信息；来源收益表现不能直接外推到A股短持有策略。
