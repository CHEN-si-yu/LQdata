# A股日频因子资料库

本目录整理 168 个原有文件，并补充 93 个在线来源、1367 条因子与特征研究记录。资料用于研究查阅，涵盖公式、论文证据、数据字段和研究方法；记录类型与证据范围分别标注。

## 计数与适用范围

Qlib有518个默认特征维度，其中505个窗口或滞后变体；Alpha101和Alpha191共292个编号公式；学术复现目录有331条元数据，其中119条来源标为Placebo或Drop。另有47个米筐风险暴露、57条数据字段、论文机制和研究方法。以上数量不能解释为独立有效Alpha数量。

国外证据、月频/周频检验、分钟级任务和A股日频研究分别注明。`definition_verified`表示读到了支持该概念或定义的内容，不表示已运行、已复现收益或具备交易可执行性。`include_in_candidate_view`只是排除字段、风险暴露、方法、待测参数及来源弃用记录的浏览辅助，不表示已批准或已验证。

## 原文件与参考快照

原有168个文件仅移动分类，名称和字节内容保留。迁移路径、编码与SHA256见 [原有资源清单](索引/原有资源清单.csv)；整理前清单与内容校验也保存在索引目录。聚宽TXT主要采用GB18030，阅读乱码时可选择对应编码。

仅对已有明确许可的Qlib源码和OpenSourceAP元数据保存参考快照，附许可证、固定commit及校验值。其他来源保存原始链接和自写摘要。未开发或执行因子实现，也未调整研究/生产入口。

调研与整理日期为2026年10月7日。后续新增资料沿用当前目录与索引字段，具体变体和来源版本分别记录。
