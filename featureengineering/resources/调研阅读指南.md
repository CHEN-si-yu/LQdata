# A股日频因子调研阅读指南

A股日频研究需要同时明确公式、数据可得时点和持有执行条件。资料库按主题保存原有资源，并把新增资料分成因子定义、编号公式、参数变体、目录线索和研究方法。先选能取得可靠历史数据的机制，再阅读原文口径；文献结果和平台因子名字不能直接替代自己的验证。

## 因子方向与数据需求

| 方向 | 关注的机制或字段 | A股日频阅读重点 |
| --- | --- | --- |
| 动量和反转 | 历史收益、残差收益、趋势强度 | 区分股票与行业、隔夜与日内、回看窗口与跳过期；国外动量结果不能直接移植 |
| 技术形态和价量 | K线形态、均线偏离、价格位置、量价相关 | Alpha101、Alpha191、Qlib的类似名称可能使用不同算子、窗口、单位和归一化 |
| 流动性和成交 | 换手、成交额、成交冲击、零成交 | 按来源定义核对量额单位与分母；停牌和缺数据不能统一视为零 |
| 风险和尾部 | 波动、特质波动、偏度、极端日收益 | 风险暴露与预测信号用途不同；MAX等机制的原文频率与目标需单独确认 |
| 估值 | 盈利价格比、账面市值比、现金流市值比 | 核对负盈利、负净资产、流通与总市值，财务口径按披露日可得 |
| 盈利和成长 | 毛利率、盈利能力、增长与盈利意外 | 同比与环比、单季与累计、点值与TTM分开；保持历史公告版本 |
| 投资和资产结构 | 资产增长、投资、营运资本、融资变化 | 美国会计字段需映射到中国报表；财报公布前不能把期末值填入历史 |
| 应计和现金流 | 应计利润、现金转换、经营现金流 | 核对定义是现金流法还是资产负债表法，季度累计项是否需拆分 |
| 公告与事件 | 盈利公告、业绩预告、股东交易、限价事件 | 事件时间、首次可交易时间和修订时间分开；分钟文献需先评估是否可日频聚合 |
| 投资者行为 | 关注度、资金、持仓、预测修订 | 公开网页当前值不等于历史快照；北向、机构与卖空字段不能跨制度直接替换 |
| 行业与市场状态 | 行业内相对值、广度、行业动量 | 区分个股横截面因子、市场时间序列和资产轮动策略，不把三者效果混用 |
| 自动挖掘与机器学习 | 表达式搜索、因子组合、预测特征 | 方法和模型不是单个因子；特征数量、窗口变体与独立机制数量分开 |

以上是本资料库的整理框架，不是某一篇论文的实证结论。具体来源和定义见各记录的 `source_ids`、`source_urls` 与主题报告。

## 日频观测与日频更新

价格成交信息通常可以随交易日更新。财务、机构持仓和分析师信息按披露或修订时点改变，将已知值保持到每日属于日频映射，并不意味着每天披露了新信息。论文中的月度排序、周度动量或日频组合收益，也不自动等于每天形成的新信号。

读取记录时同时核对三种频率：原始数据观测频率、信号更新时间、研究目标和持有频率。来源只支持月频或分钟级结论时，目录会保留这一限制。

## 公式与来源核对

同名因子的差异经常来自以下口径：价格复权方式、收益起止点、窗口最小有效样本、截面排序还是时序排序、权重与行业中性化、分母和缺失处理。Alpha101或Alpha191编号只在其对应的来源版本中有明确意义；跨仓库复现应回到原始定义核对。

明确机制记录提供自写摘要，不承担完整实现规范的作用。原始定义以来源链接、公开文档或获许可的参考快照为准。Qlib特征按默认配置展开，滞后项和不同窗口作为参数变体记录。学术复现目录包含来源列出的Predictor和Placebo；目录分类不能作为A股有效性保证。

## A股信息时点与样本

研究记录应保留公告日期、可得时间、报告期和历史修订版本。使用当时尚未披露的财务值、事后调整的股票池或后来的行业分类，会改变历史信息集。价格收益与价格水平所需的复权处理也需分开核对，不能直接拿当前前复权序列解释历史已知价格。

交易成本、停牌、涨跌停和无法成交会影响可执行结果。原文组合是否能做空、是否包含微盘股、是否排除金融股、如何处理退市股票，都属于证据适用范围的一部分；这些条件不能从“因子有显著收益”一句话省略。

## 阅读路径

1. 从 [资源入口](README.md) 和 [原有资源目录](索引/原有资源目录.md) 选择主题。
2. 在 [因子记录总表](索引/因子记录总表.csv) 按主题、所需数据、记录类型和证据等级筛选。
3. 在 [来源总表](索引/来源总表.csv) 查看已核验范围及访问限制，再进入对应原始来源。
4. 对A股研究优先阅读 [论文与学术证据](新增调研/论文与学术证据/README.md)，对具体表达式和算子阅读 [GitHub因子库](新增调研/GitHub因子库/README.md) 与 [平台和比赛](新增调研/平台与比赛/README.md)。
5. 想扩展经典机制时查 [学术复现目录](新增调研/学术复现目录/README.md)，优先检查数据能否映射到A股，再阅读精确定义。
