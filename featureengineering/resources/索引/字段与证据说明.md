# 资料索引字段与证据说明

原有资源索引描述本地文件；来源总表描述在线资料及核验范围；因子记录总表描述研究线索、机制、特征变体或方法。三者用途不同，文件数量和记录数量不能直接解释为独立有效因子数量。

## 原有资源清单

`old_path` 与 `new_path` 是迁移前后相对于resources的路径。`sha256` 对应原始字节，`encoding` 提示文本打开方式。`topic` 按标题与可读首屏分类，多主题资料可通过标题或交叉主题标签检索。来源网址从原文件中提取，属于原文件给出的引用，不代表本次逐一重新访问。

`classification_basis` 记录分类依据。原文件标题中的收益、胜率和效果表述原样保留，不视为本次调研结论。目录不删除资料，也不将期货、ETF、分钟策略默认解释为A股个股日频因子。

## 在线来源

| 字段 | 含义 |
| --- | --- |
| source_id | 本资料库的来源标识，用于连接因子记录 |
| title 和 url | 资料标题与原始来源链接 |
| source_type | 论文、官方文档、GitHub、比赛等来源类型 |
| accessed_at | 本次核验日期或时间 |
| verification_status | 实际核验到的范围 |
| license | 源码或内容使用条件；无许可内容保留链接和自写摘要 |
| summary 和 limitations | 来源支持的内容与不能外推的范围 |
| commit 和 snapshot | 适用时记录固定版本与本地参考快照 |
| aliases | 同一来源合并时保留旧来源标识 |

核验范围通常包括 `full_text`、`abstract`、`metadata_only` 和 `access_limited`。`verified=true` 指来源信息已核验，不表示某个因子公式、收益或A股适用性全部得到证明；需结合该来源的核验范围阅读。

## 因子与特征记录

| 字段 | 含义 |
| --- | --- |
| factor_id 和 name | 可定位的记录标识与名称 |
| category | 研究主题 |
| record_kind | 明确机制、编号公式、参数变体、仅名称编号线索或研究方法 |
| definition_summary | 自写概念摘要；原始精确定义以链接为准 |
| definition_verified | 实际读到支持该定义的内容；不表示已运行或已验证收益 |
| required_data | 研究所需数据及可能的额外来源 |
| frequency | 数据、信号或文献频率及适用限制 |
| a_share_relevance | A股直接证据或跨市场迁移判断 |
| evidence_level | 对应证据范围 |
| source_ids 和 source_urls | 来源连接与原始链接 |
| pit_notes 和 limitations | 信息时点、执行与迁移的具体注意事项 |
| include_in_candidate_view | 浏览辅助过滤，排除字段、风险暴露、方法等；不表示验证或批准 |
| source_group 和 record_file | 原始专题与JSON位置，便于回查 |

`record_kind` 的统一值为：

- `mechanism`：有明确概念的机制或因子定义，仍可能需要阅读原文细节。
- `formula_record`：来源明确列出公式的编号记录，摘要描述输入和算子；不等同独立经济机制或完整实现规范。
- `parameter_variant`：同一机制的窗口、滞后、字段或其他配置变体。
- `factor_id_only`：仅可定位名称、编号或目录条目，不能当完整定义使用。
- `method`：搜索、模型、评价或组合方法，不计为独立因子。

同名记录只有在定义和口径一致时才适合合并。总表保留跨来源表述差异，用交叉引用标出相同规范名称，避免凭名字抹平公式差别。CSV采用UTF-8 BOM便于表格软件打开；JSON采用UTF-8，保留列表和扩展字段。
