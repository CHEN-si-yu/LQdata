# 第四版补充：可评价截面的区分度

本补充延续用户“适度放宽，以有效性和现库风格差异为核心”的授权。第四版冻结正文和哈希保留，本补充另行冻结并用于之后的审核及明确登记的复审。

发现的问题：稀疏事件N007在1462个有值日中有345日仅一只有值股票，另外1117日全部非常数。原有值日口径把单股日纳入常数率，使其得到76.40%的G3；但一个观察值不足以识别截面区分度。该诊断在读取N007任何收益标签之前得到。

统一口径：G3准入比例在候选当日至少100只有效股票的可评价截面计算，阈值仍为C>=90%、GC>=95%。同时必须原样报告全期、有值日、单股日、2–99股日和至少100股日统计，不能隐藏稀疏性。没有可评价截面的候选不通过G3。C的G2仍单独要求全期至少20%的日期达到100股，不能用G3分母调整替代覆盖门槛。

这项调整不删除、补零或改变因子值，公式、方向、持有窗口和参数均不变；G4和G7仍只用每日至少100个共同有效样本。真实的大截面常数继续拒绝，例如E032在2021–2026全池为零仍不通过。只在几个股票上可算的复牌事件也不会因此通过G2。

本口径统一适用于所有新候选和登记复审，不为N007改变显著性或收益方向。已完成的原始G3结果与原裁决保留，并分别列出v3、v4原口径和本补充口径。N007现在只获准继续一次原正方向的收益检验，不是获准入库。
