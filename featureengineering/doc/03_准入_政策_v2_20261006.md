## 〇、三条通道并行

| 通道 | 用途 | 门槛 |
|---|---|---|
| **绿卡通道（描述量）** | 扩容主力：透明的单序列标准变换/观测描述量；**不主张预测方向** | 三项基础门槛（非空/非常数/无泄露）+ verify + 登记去重；元数据标 `admission_tier="GC"`、`G4-G7 not claimed` |
| **v1 严格档**（R5 冻结，原样保留） | 常规 alpha 准入，证据最强 | G1–G7 原阈值 |
| **v2 放宽档**（本文件） | alpha 提速扩容；元数据标 `admission_tier="B"` | 见下 |

绿卡通道依据用户 2026-10-05 裁定（三项基础门槛 + 市场绿卡「透明观测描述量」规则，31 个股票绿卡据此入库，
2026-10-06 用户再次确认放低门槛与扩容目标）。绿卡不装成 alpha：报告与元数据一律写明"未主张 G4–G7"。

**绿卡通道的额外纪律（2026-10-06 冻结）**：
- 登记去重：名称/构念/代数恒等 vs 在库（211 项）与 374 已删记录，同 F1/F2/F3 口径；
- 窗口/期限变体仅以**期限结构**登记（同一估计量 ≤5 个，短/中各 1–2 个），不得网格扫描；
- 与在库对象 pooled |ρ| **必须测量并记录**：≥0.98 的新对象不得入（近重复，只保留代表作）；
  0.95–0.98 记录为软带并交主裁判复核；
- 缺失约定、PIT 口径、`delay_days` 依在库合同；稀疏/事件型同样适用 H6。

下游可据 `admission_tier` 决定是否使用；GC/B 档是"证据分级明确"的合法资产，**不是**"免检资产"。

## 一、不可放宽的硬规则（H 组，三通道相同）

| 硬规则 | 内容 |
|---|---|
| H1 工程验证 | `research verify`：真实输入截断 + 两阶段增量重放，float32 value/rank、NaN、键精确一致；完整轴、无 Inf。缺 verify 不得入库。 |
| H2 方向预注册 | declared/raw 双列；`higher_is_better` 冻结后不得反号、不得事后改向。稳定反向只能作为下一轮独立事前假设。 |
| H3 差异底线 | 与任一在库股票因子 pooled 平均日度 \|ρ\| ≤ **0.95**（硬线，不放宽）；frac_days(\|ρ\|≥0.99) 必须报告。 |
| H4 结构同构检查 | 构造前对照 `doc/因子清理记录_20261003.md` / `市场因子清理记录_20261004.md` 查重蹈；不得是现库因子的排序/代数同构（正反写法、腿置换、单调变换）。 |
| H5 无前视 | 敏感性变体必须核查可用性假设；财报 PIT/公告日口径不变。 |
| H6 缺失约定 | 稀疏/事件候选必须 NaN 条件与零填充双口径并报，符号不稳健者不得准入（§D.5）。 |
| H7 半离散 | unique/day 低（如 <50）或零占比高的候选，必须先做联合重建/混淆检验（§D.2、R4-4）。 |

## 二、放宽档统计门槛（B 组）

| 门 | v1（严格档） | **v2（放宽档，新默认）** |
|---|---|---|
| G2 覆盖 | ≥60% 交易日有 ≥100 只有效票 | **≥40%**（事件/季节型结构因子适用；仍须报 active-day 统计与旗标） |
| G3 非常数 | ≥95% 有效日截面 std>0 | **≥90%**（附 unique/day 与零占比报告） |
| G4 信号 | h=1 或 h=5 declared RankIC HAC95 下界>0 且正向年份 ≥7/9 | **h=1 或 h=5 HAC95 下界>0 且正向年份 ≥6/9** |
| G5 差异 | ≤0.95 硬线；>0.90 需论证 | 硬线不变；**>0.85 需论证** |
| G6 稳定 | 主裁判排除单年主导 | 不变（软门，逐年表必报） |
| G7 增量 | 同一期限双口径 declared t 均 ≥2 且正向年份 ≥7/9 | **双口径同号，max(\|t\|) ≥1.65 且 min(\|t\|) ≥0.5；增量正向年份 ≥5/9** |

- G7 控制组：base8 = `momentum_120, short_term_reversal_5, vol_120, idio_vol_60, log_mv, turnover_std_20, bp, roe_ttm`。
  波动率族补充控制冻结为 `idt_rv_daily, id2_parkinson_vol, atr_14_ratio`（**不含已删除的 `var_95_20`**；AGENTS.md §B 的
  `var_95_20` 条目为历史遗留矛盾，以本冻结为准，已在此裁决）。
- 主期限仍为 h=1、h=5；支持期限必须在裁决中写明（B 档允许"仅单期限支持"）。
- **G7 绑定控制组 = base8（冻结）**；家族特定补充控制（如波动族三项、WC/应计等）作为**稳健性列报**、
  不作 v2 绑定门（理由：跨家族口径统一、可批量判定；v1 的相关细则随 v1 保留）。若补充控制下
  双口径 max <1.65，catalog 必须标 `weak_increment=true` 并在裁决中写明数值。

## 三、流量与质量护栏（防堆量不代表防堆垃圾）

1. **机制多样性优先**：同一家族/机制的窗口与参数扫描按预登记预算执行（默认一族 ≤4 变体），
   窗口近邻（如 20/21/22 日）视为同一表达，只登记预选代表。
2. **批量检验意识**：按批统计"尝试数/通过数"并落盘；B 档通过但 t 在 1.65–2.0 的因子在
   catalog 标注 `weak_increment=true`，供下游与后续复核。
3. **A/B 档判定自动化**：裁决脚本按本文件阈值自动给出门序结果，主裁判复核边界个案。
4. B 档因子照常走完整生命周期（candidate→qualified→shadow→production）、同源 eval+verify、正式发布。

## 四、对历史候选（R4–R11 及 legacy）的适用

- 已有同源 eval+verify 证据的候选：按本政策**重新裁决**（阈值用 v2），证据新鲜度按
  `research/lifecycle.py` 的 identity 检查执行；失效的补一次 verify。
- 证据不全者：补相应门（G5/G7/verify）后裁决；仅"记录通过"的 legacy 条目须复现后裁决。
- 已入库因子（含软带 0.9–0.95）一律保留；>0.95 冲突项（如 `r10gc_ret_std_63`，由用户 2026-10-05
  授权入库）保留并加注冲突记录，后续同类**不再放行**（硬线维持）。
