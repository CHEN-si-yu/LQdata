# 市场因子复审报告（market_review_20261003）

## 一、摘要

本次复审为 61 个市场因子建立了完整的准入体系（绿卡/严格两通道、M0–M7 门、方向预注册与门序裁决），
并以冻结规则对其做了全量重审。**结论：34 个透明观测描述量获「绿卡准入」（描述用途）；27 个构造型因子
全部落「待修订」——无一通过严格通道（M5 预测检验 0/27、M6 增量检验 4/27、交集为空）；0 个「建议剔除」**
（按门序，M5 未获支持者先行待修订；17 例增量符号反转已如实记录为优先复核项，不在本次升级为剔除建议）。
全部处置仅出结论与建议：未删除、未降级、未改任何生产状态。

- **绿卡通道**（透明观测描述量：计数/比例/分位/均值/中位数/标准差/指数行情及其标准变换）：
  M0 结构 + M2 覆盖与变化 + M3 口径与可用性；**不声称预测有效性**。
