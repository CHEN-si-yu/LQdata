# 因子设计方法与真实失败案例

这些是 R14 研究中改变决策的经验，文中的待审、停止和阶段结果按当时状态理解；后续交付查阅[R15交付](04_研究记录_R15交付_20261008.md)和[R16交付](04_研究记录_R16交付_20261008.md)。这些案例不是保证收益的通用配方。选定方法后必须重新核验当前现库和数据。

## 从机制生成有区别的表达

| 方法 | 合理的研究问题 | 必须排除的伪差异 |
|---|---|---|
| 创新项 | 当前状态相对自己的季节性与趋势是否异常？ | 只是对水平值标准化；使用未来拟合趋势 |
| 结构份额 | 在同一经济总额中两种权利/现金流的构成如何？ | 未匹配范围或时间；缺失冒充零；分子已在分母外 |
| 条件反应 | 价格对成交额、负冲击或市场状态的响应是否改变？ | 简单把已知因子与状态乘起来就宣称新机制 |
| 路径顺序 | 相同累计收益下，障碍等待、回撤顺序或响应滞后不同吗？ | 只由收益分布决定的指标换名字 |
| 时间分配 | 日内流动性或成交量到达时序与历史预期有何偏离？ | 逐笔成交构念用5分钟端点冒充 |
| 传播网络 | 同业已公开的新信息对尚未披露公司有何影响？ | 最新行业/持仓回填历史，或本公司事件强度解释全部增量 |
| 动态参数 | 风险暴露变化速度是否稳定可识别？ | 优化器成功但弱识别、边界解、大量 null 假阳性 |

“因子残差化”不是万能去重方法。残差依赖控制集合、变换、样本和时点；先说明经济对象，再固定控制并检验。不要用全样本 PCA、回归或标准化构造历史因子。

## 财务：公告前沿和零值

财务字段先核验供应商实际口径，再对照公司官方报告。单位错1000倍会改变阈值和样本；简单比率单位相消也不能因此跳过对账。核验至少涵盖分子、分母、报表合并范围、年度/YTD、净额/总额和公告日期。

F001 成功范例：现金转换周期 CCC 的季度季节趋势创新。先构造严格匹配的 TTM，使用前12个准确季度拟合趋势和季度季节项，当前残差按历史 RMSE 缩放。意义来自“偏离自身正常经营结构”，不是把 CCC 改个窗口。近邻包括原 CCC、库存与应收现金关系；真实补控后仍保留弱增量，正式和生产逐值一致才入库。

F007 描述范例：正合同资产/(正合同资产+正应收)。源中的零值含未披露歧义，因此两个腿都严格为正，明确这是净账面权利构成及正披露子样本；不得用未来首次出现正值来推断早年零值真假。

F008 失败范例：现金流压力下削减研发的原负方向。样本中大多数门控为真零，方向证据与固定补控不足；经济故事不能替代证据，也不能翻号入库。

F015 待审范例：少数股东资本现金/总资本投入现金。严格 TTM、同现金流前沿、分子≤分母，实际官方报表字段对账。结构清楚只说明值得继续审，不等于通过当前现库 G5 或正式回放。

常见构念错误：货币资金减现金等价物不能自动代表受限现金；递延所得税总额变化不等于税损资产减值；固定资产变化不能识别维护性资本开支；政府递延收入总额不能识别当期补助摊销。需要匹配附注、类别或资产批次时，没有这些数据就记录缺源。

## 价格：真实成交端点和预热

收益 `r[d]` 必须按该公式检查 `traded[d-1] & traded[d]`。若用 `r[d]` 预测 `r[d+1]`，完整样本要检查 `d-1,d,d+1`。价格层填充停牌日期能维持轴，却可能让恢复交易收益跨越很久；固定600自然日预热无法找回多年前最后价格。

P009 v1 正式/初筛出现304个差异，集中在长期停牌恢复交易后的跨年窗口。根因是左成交端点缺失而不同预热看到不同旧价格。修复明确相邻真实交易端点，重新登记 v2 并重做值、G5、工程证据。不能把这些差异归入 float tolerance。

预热验证方法：选跨年、长期停牌、上市、缺失源等有意义股票，比较完整历史与年度同初始化输出；检查非空有效区间。`warmup_days` 是自然日，504交易日不能写504自然日；递推/PCA/状态估计还要固定锚点。

P006 成功范例：60个已完成月收益的原始累计前景理论效用。完整月末端点必须实际成交，使用交易日历确认月份完结，61价格端点与足够预热。原论文市场超额版本与实际原始收益分支要分别描述，不能混称。

P013 路径探针：在收益多重集、终点与绝对路径长度相同的合成路径上，顺序变化使障碍等待差异改变。说明可区别于分布指标；仍需报告未触障碍的截尾比例，受限等待不能称真实无限等待时间。

P014 估计探针：HAR 风格月度部分记忆系数先用合成真参数、置信区间覆盖与条件数验证。日内 Parkinson 高低价范围不是逐笔 realized volatility，必须准确命名代理。

P016 停止范例：随机游走 beta 的扩散参数 Q。在常 beta null 中仍有6/20被简单工程门槛识别，弱Q大多边界，profile likelihood接近零扩散且标准误很大。正 Hessian 和内部解不足以证明 Q 可识别，应停在识别层而不是扩大计算。

## 分钟：单位变更与低内存扫描

日线 vol 是股，amount 是人民币。分钟源曾在2025-12-01前后由手变股；采用基础层实际归一化逻辑及跨过渡样本核验，不靠旧说明猜单位。

M002 的上午/下午价格变化-金额非流动性差异是价格/金额代理，不能称买卖价差。两时段字段全部有限正值，避免不对称缺失制造“差异”。

M013 只测5分钟收盘价变动端点在5分价格格上的集中度，不是交易逐笔价格聚集。需完整48根网格、同一时段相邻变化、原始价格分/元核验；停牌、不完整日不计为0。

M014 的成交量累计分布相对前20个官方交易日预测偏离，日内归一化能消除整日统一×100的单位变化。仍应检验跨单位切换和缺失日；这个不变性不能代替所有源核验。

216,466,718行全期分钟扫描曾以约0.74GiB RSS完成；正式 ctx.dataset 单年读取峰值约4.68GiB。两个内存路径不同：研究流式扫描的低峰值不能用于承诺正式多进程内存。正式适配器必须走可得性审计 API，并与流式同窗口精确对拍。

## 事件与网络：覆盖和家庭控制

当前字段不是历史映射。`is_hs`、最新控制人、当前行业、最新持仓不允许回填历史。指数日线没有调入调出名单和权重，不能据此构造被动资金再平衡需求。

事件现金/持仓/数量的字段需要经济同义核验。股东户数不是基金份额，股权质押比例不是共同质权人网络，减持公告额度不是真实成交。

E032 年轻上市指标失败：固定池最后上市时间使2021–2026全池为0，覆盖虽100%，可评价截面非恒定仅约34.24%。不改年龄窗来绕过原质量失败。

N006 财务同业图：资产结构取历史可得同报告期截面，月末前冻结近邻，传播严格下一交易日公开的季度创新。完整固定方向 G4 失败，不能用条件样本有利回归救场。

N007 公告拥挤与本公司盈利创新：原 h1 IC 和 BASE8 通过，但原创新、拥挤强度、事件年龄三项联合后两核翻负。说明结果可由组成腿解释；低单因子相关不构成独立增量。

N014 跨拟合 PCA-OU 位移：月末历史窗口训练，目标整组排除出 donor，严格相邻成交，全部投影和参数按过去数据估计。强单项 IC 在真实4控制后大幅收缩；仅 h5 保留弱核t=.3774、强核t=1.8963。可继续审但应标弱增量，不能把“PCA+OU”名称当差异性证据。

稀疏事件的控制要区分“已确认无事件=0”和“事件数据未知=NaN”。缺失控制不能见结果后改为0；固定缺失规则后报告联合共同样本与相同样本 BASE8。

## 工具与报告的实际坑

- `extra_controls` 参数可能只在输出写名字，没有进入设计矩阵。检查真实联合回归输出、系数、样本数和秩缺陷。
- 注册工具生成含 hash 的 ID；保存实际返回值。拼写正确的猜测 ID 仍不存在。
- 基线 JSON 不一定有 `is_label/is_market` 字段；读取实际 schema，使用正式规格分类，不用不存在的字段默认猜测。
- 不对 `*py` 通配符逐文件 cat，可能误匹配 `.npy` 并倾倒二进制。文本读取限定扩展与长度；数组只输出形状、dtype、统计与 SHA。
- 复用旧固定227因子缓存后追加当前新增正式对象，不把旧“全部”当当前“全部”。
- 全 NaN 的两个结果相等不证明实现正确。每个关键对拍有有效值，并核查完整轴、NaN和 rank。
- 资源报告说明时间和口径：RSS、PSS、cgroup、席位利用率和CPU各自不同。
- 不覆盖冻结文件。记录新的政策/修复/裁决，链接旧结果；文档中的历史计数不冒充当前台账。
