# 股票因子准入政策 第三版 2026年10月6日

本版依据用户本次追加授权冻结：略放宽统计审核，复查历史失败候选和本地资源，持续研究至正式股票因子总数达到 1000，或用户明确停止。工程、数据时点及结构去重继续审核。旧版政策及旧裁决保留，本版不改写已有结果。

## 适用与重新审核

本版用于冻结后开展的新候选和明确登记的历史候选复审。正在计算的本轮候选同时保留原 v2 结果，并单独列报 v3 判定；不得把未过 v2 写成已过 v2。历史复审保留原始公式、参数与声明方向，记录历史失败原因和本版适用范围。涉及实现修复必须创建新版本，再计算和验证。

新的统计通道标记为 `admission_tier=C`。它表示初步预测证据，不能称为已证明长期有效或独立样本外确认。透明描述量仍使用 GC 通道，不主张预测方向。失败的 alpha 不能事后改名为 GC 绕过裁决；描述量必须先独立冻结用途和定义。

## 预测候选的统计门槛

| 门槛 | 第三版 C 通道 |
| --- | --- |
| 覆盖 G2 | 全期至少 30% 交易日有不少于 100 个有效股票值，保留全期及活跃日统计 |
| 非常数 G3 | 有值交易日中至少 90% 截面标准差大于 0，报告不同值数量和零值比例 |
| 信号 G4 | h1 或 h5 的声明 RankIC 均值为正，HAC 双侧 90% 区间下界大于 0，至少 5 个年度均值为正 |
| 差异 G5 | 固定正式股票基线的平均日度绝对 Spearman 不超过 0.95；超过 0.85 须解释差异；报告绝对相关达到 0.99 的日比例 |
| 稳定 G6 | 报告逐年及逐年剔除结果，由主审检查单年主导与时间失稳，不能仅凭全期均值通过 |
| 增量 G7 | 支持 G4 的同一期限中，平均并列秩与模型消费变换两种内核的声明系数及 HAC t 都为正；较强 t 至少 1.30，较弱 t 至少 0.25；两内核各至少 4 个正年度，较强内核至少 5 个正年度 |

G7 绑定控制组保留 base8：`momentum_120, short_term_reversal_5, vol_120, idio_vol_60, log_mv, turnover_std_20, bp, roe_ttm`。每日共同有效样本至少 100，设计矩阵满秩。家族补充控制事前固定，作为稳健性列报，不能根据结果删掉不利控制。原始与声明方向双列，禁止对声明结果再次翻号。

所有 C 通道对象均明确标记 `weak_evidence=true`。较强增量 t 小于 1.65、较弱 t 小于 0.50、补充控制削弱信号或年际不稳定者同时标记 `weak_increment=true`。这些字段供使用方识别证据等级，不触发对下游工程的自动修改。

## 工程与数据审核

正式准入仍须同一计算运行的正式评价与真实验证。`research verify` 必须完成实际输入截断和两阶段增量重放，float32 value、rank、NaN 和完整键轴逐值一致。无封存运行、缺证据、数据轴不完整或含 Inf 均不得准入。

公式、方向、可用时点、缺失处理与参数预算在实验前冻结。财报仅使用可见的整行版本；无法识别的历史修订不重造。只用项目配置声明的原始源，上游只读，不读或改下游业务数据。

结构检查覆盖现库、历史删除及已研究近邻，排序同构、代数恒等和相反写法不能作为新信息。稀疏事件同时报告 NaN 条件与零填充敏感性；半离散或大量零值须完成联合重建和混淆检查。源单位、分段、有效观测计数等实现错误必须先修复，不属于可放宽的统计门槛。

## 透明描述量 GC 通道

GC 是有明确物理、会计或价格含义的观测描述量，不主张 G4 和 G7。要求实际非空、至少 95% 有值交易日截面非常数、真实工程验证和数据时点正确，不能只把随机噪声、无意义组合或常数送入正式库。

GC 的相关阈值按其专用规则执行：平均日度绝对相关达到 0.98 的新描述量不入库；0.95 至 0.98 交主审解释实际含义差异；低于 0.95 仍做结构查重。这个阈值不适用于 C 通道。此处明确消除 v2 中通用 0.95 条款与 GC 专用阈值的文字冲突。

同一估计量最多 5 个预选期限，相邻窗口不计新表达，不扫描参数网格。原始字段及派生描述量都应说明单位、经济含义、版本和可用性，数量目标不能代替这些检查。

## 台账与停止条件

按方向、参数候选、进入正式库、审核中、统计失败、工程修订和重复筛除分别记账。每 30 分钟在对话窗口汇报，并保存时间戳及证据引用；经验总结保存到项目文档。C、B、A 和 GC 各自列报，避免将描述量数量误称为已验证 alpha 数量。

股票总数以正式发布清单与因子字典中的 `kind=stock` 为准，不含市场对象和标签。达到 1000 或用户明确要求停止时停止新研究，保存当前计算、审核与发布状态。冻结副本、本文哈希和工具版本保存在本轮 `freeze` 目录。
