# 市场因子审核体系（2026-10-03 制定，随复审 freeze 冻结）

> 适用范围：`data/market_factors/` 下的全部市场标量（每天恰有一行的 `trade_date/value` 序列）。
> 本文是市场因子准入的规则文本，与 `doc/AGENTS.md` 的股票 G1–G7 体系平行、互补：
> 股票因子做横截面 alpha 审核；市场标量没有同一天股票间排序，**不计算虚构的横截面 IC**
> （沿用 `doc/项目手册.md` 第 81 行既有口径），其有效性审核在本体系内独立定义。
> 本文全部阈值与统计设计在任何结果统计之前冻结（seal 见 REVIEW freezew文件）。

## 一、两条准入通道

市场因子按**因子主张**分两条通道准入，通道归属逐因子预登记（`registration/channel_direction_table.json`），
登记之后不得因结果改判通道：

### 通道 A：基础状态量绿卡（basic_context_green_card）

- **资格规则**：因子值 = 对原始字段的**直接观测统计量**——计数 / 比例 / 分位 / 均值 / 中位数 / 标准差 /
  直接指数行情，以及对单序列原始字段的**标准变换**（收益率、N 日动量、均线偏离、回撤、滚动极值位置、
  波动率、振幅、横截面半矩）。
- **排除（→通道 B）**：跨序列复合（两条及以上聚合或序列相减/相除形成的新量：价差、比值、差）；
  对已聚合量的再运算（变化率、量比、平滑/MA of ratio）；事件/条件构造（需要先判定事件或条件再聚合：
  破板率、反转回补率、封单占比、连板结构）；集中度指数（HHI）；滚动相关/回归类构造；
  同字段类别计数之差（净额构造）；需要联想解释的构造（轮动速度、leader spread 等）。**边界案例从严**。
- **门槛**：M0 + M2 + M3（M4 只记录不判）。绿卡 = **描述性上下文量**，明示「未做收益有效性承诺」；
  绿卡不是严格通过，不得表述为「已验证信号」。

### 通道 B：严格审核（strict signal track）

- 面向**声明预测性**的构造型因子；必须从预登记的 Idea/机制/方向出发，通过 **M0–M7 全部**。
- 本通道对既有因子的复审为**追溯登记 + 回顾性检验**（`retrospective_screening;
  historical_selection_is_not_untouched_holdout`），结论不得表述为未触碰样本上的未来保证。

## 二、M 门定义（阈值冻结）

| 门 | 内容 | 判据 |
|---|---|---|
| **M0 结构合同** | schema/网格/每天一行/无 Inf/对齐前缀纪律/台账一致 | `main.py check` 市场分支全部通过（复用 fea/validation.py 口径，含 align_fill 前缀豁免） |
| **M1 工程因果** | research verify：截断复算 + 两阶段增量重放 | `compare_frames` 逐值相等（float32 精确、NaN 相等、finite>0），fixture 哈希一致 |
| **M2 覆盖与变化** | 声明起点后的有效覆盖与非常数性 | ①声明起点（`resolved_start`，对齐前缀不计）后有效日 ≥98%；②全历史去重值 ≥10；③每个有效年（≥60 个有限日，**对齐前缀年不计**——前缀是契约常量、不参与退化检测）去重值 ≥2；④声明对齐前缀之外无前缀有限值（`align_fill` 声明与实际一致，否则失败） |
| **M3 口径与可用性** | 逐因子书面口径 + 静态泄露检查 | 元数据表（样本域/单位/可用时点/滞后声明）成文；`main.py audit-pit` **静态**检查通过（margin 族 `lag_grid` 等）；抽样动态复算仅作辅助证据（不参与门判定） |
| **M4 去重** | 61×61 时序 Spearman（共同有效日 ≥250） | \|ρ\|≤0.90 通过；0.90<\|ρ\|≤0.95 需书面论证（族内近亲必查）；\|ρ\|>0.95 判不通过（需合并取舍）。绿卡因子只记录与标注 |
| **M5 预测检验** | 预登记方向的时序预测检验（主期限 h∈{1,5}） | 统计量：共同样本 ρ = mean(zrank(因子)·zrank(前视目标))；HAC-Bartlett(19) 95% 区间由 `fea/eval.py::mean_uncertainty` 对逐日乘积序列给出；分年 ρ_y=年内乘积均值（年内共同有效日 ≥60 才计入年）。**通过 = 在 h=1 或 h=5 上：declared 区间下界 >0（= 区间排除 0 且符号与预登记方向一致）且 同号年数 ≥ ceil(7×有效年数/9) 且 有效年数 ≥6**。主目标 = 前视等权市场收益（由正式 `label_ret_hd` 面板按日横截面均值派生）；辅助目标（仅报告）：沪深300/中证500 指数 open-to-open 前视收益、前视离散度（std）、前视宽度（share>0） |
| **M6 增量检验** | 对冻结控制集的市场级 HAC-OLS | 回归：zrank(主目标) ~ zrank(候选) + zrank(控制集)；控制集冻结 = {mkt_idx_csi300_momentum20, mkt_idx_csi300_volatility20, mkt_dispersion, mkt_up_ratio, mkt_margin_balance_chg20, mkt_am_amount_ratio20}（候选自身在控制集中时自控制排除）；Newey–West/Bartlett lag 19；共同有效 n≥250。**通过 = 在 h=1 或 h=5 上 declared t ≥ 2.0**（declared = raw×预登记方向；即符号与登记方向一致且 \|t\|≥2）。同报告 raw/declared 双列与剩余方差比例 |
| **M7 机制审议** | 追溯 Idea 登记 + 逐因子裁决 | Idea/Family/Candidate 已在研究目录按合法约束登记（before 统计）；机制陈述先于统计成文；裁决按第四节规则树执行；全部报告 raw/declared 双列 |

### 方向登记纪律（沿用股票 R3 教训）

- 方向 ∈ {+1, −1, 0}：**严格通过要求已注册 ±1 方向**；方向=0 表示无方向先验（不能严格通过，检验结果仅作辅助报告）。
- 方向仅依据公式语义与机制推导，在 M5/M6 之前成文封存；**禁止**看到结果后改方向、改 `higher_is_better`、换版本把方向扳回来。
- 方向先验强度（强/中/弱）如实标注；弱先验因子的通过/失败结论须在裁决中说明先验强度背景。

## 三、复审执行与证据

- 执行环境：只读生产产物与上游；全部新产物写 `artifacts/research/market_review_20261003/`；不写 `data/`、`state/`、`conf/production.json`。
- 证据：freeze（规则+方向表+源哈希+输入指纹+脚本哈希，兼作 research batch 的 source freeze）、
  `gates/m0..m6` 逐门证据、`verdicts/` 总表与逐因子结论、evidence_manifest（sha256）。
- M1 的逐值复算经 `research batch` + 审计别名家族（`research.families.market_gate_audit_v1`）在隔离命名空间执行；
  `research evaluate` 对市场候选仅产出 quality-only 记录，**不冒充有效性证据**；有效性只由 M5/M6 承担。
- 透明披露：方案核验阶段做过探索性统计探针（聚合层面结果已见，未写任何文件）；
  门定义来自股票先例与结构推理，未针对探针数字调参；全部写入 freeze 的 `preview_disclosure` 与最终报告。

## 四、裁决规则树（冻结）

**绿卡候选**：M0∧M2∧M3 过 → `绿卡准入`（描述用途；M4 重复仅标注）；任一不过 → `待修订`（结构缺陷先修复）。

**严格候选**（先决：M0∧M1∧M2∧M3 全过，任一不过 → `待修订`。以下规则**按门序依次应用**）：
1. M4：\|ρ\|>0.95 → `建议剔除`（重复，需合并取舍）；0.90–0.95 且机制陈述无法说明独立性 → `待修订`；
2. M5：主期限未获支持 → `待修订`（信号未获支持：建议转为描述用途或重新论证机制后复审）；
3. M6（仅当 M5 已获支持时由增量检验裁决）：declared t < 0（符号相反，风格投影特征，AGENTS.md D.1）→ `建议剔除`；0 ≤ declared t < 2（同号不显著，增量不足）→ `待修订`；
4. M5∧M6 全过 → `严格通过`（用途=独立信号候选）。

> 门序语义（2026-10-04 freeze v5 澄清，与条文一致）：M5 未获支持者**先行**落 `待修订`（即使增量检验出现符号反转，也如实记录为观察与优先复核项，不在本次裁决升级为剔除建议）；`建议剔除` 的符号相反分支针对的是「水平检验获支持、但控制既有市场因子后符号反转」的投影模式（对应 AGENTS.md D.1 的伪发现形态）。

**建议动作列**（只出建议，不执行）：保留 / 保留并标注重复 / 保留为基准控制项 / 修订后复审 / 建议剔除（仅建议，未执行）。
控制集因子不豁免自身审核（股票复审教训 §二.4）。
