# 因子研究与工程要点

本页归纳全库复审及 R04 至 R16 的研究、主审和运维经验，供接手和设计检查使用。原始轮次数字、失败经过及裁决保留在日期化文档中。准入阈值查阅 [v4 政策](03_准入_政策_v4_20261007.md)和 [v4.1 截面区分度](03_准入_截面区分度_v4.1_20261007.md)；生产操作查阅[项目手册](01_生产_项目手册.md)。历史授权、资源实测和停止目标只适用于当时任务。

## 接手时先区分四种状态

候选登记、正式计算完成、批准入库、生产物化完成分别核对。`begin.json` 和目录存在不证明计算完成；封存 `run.json` 不证明主审通过；生产注册数量不证明全部年度分区已经完整。当前清单读取注册表，实际覆盖读取产物与断点，旧字典和旧发布指针不作为当前完成标志。

R15 收尾记录的注册快照是 258 个股票因子、47 个市场因子和 5 个标签；R16 收尾为 260 个股票因子、合计 312；R17 收尾为 310 个股票因子/47 市场/5 标签（合计 362，新增 50 个股票因子，未达 500，用户指示停止）。这些是交付时点记录，后续运行仍应重新核对。R16 结束后曾暂停新方向；用户于 2026-10-18 授权 R17 继续挖掘（目标股票因子 >500），于 2026-10-19 要求停止新方向并收尾；新的因子研究仍需明确授权，R15 冻结方向仍需单独授权才恢复。详见 [R15 交付](04_研究记录_R15交付_20261008.md)、[R16 交付](04_研究记录_R16交付_20261008.md)、[R17 交付](04_研究记录_R17交付_20261019.md)和[方向冻结](04_研究记录_R15方向冻结_20261008.md)。

## 设计先说明经济对象和差异

设计至少写明机制、精确公式、真实源字段、单位、时点、缺失规则、预热、最近邻、声明方向、主期限、固定补控和允许变体。先检查现库、已删除构念和失败方向，再花算力。低两两相关不能证明新增信息，复杂公式也不能替代可识别的经济对象。

排序不变的变换、符号翻转、同机制邻窗和代数互补不作为新的独立信息。池内三项份额之和为 1 时，第三腿可能由前两腿重构；条件门控和乘积应拆开组成腿检查。N007 和网络近互补方向显示，单项 IC 或 BASE8 通过后，真实家族补控仍可能消除或反转增量。

方法和反例见[设计方法与案例](02_研究_设计方法与案例.md)、[R04 复盘](05_经验_R04复盘_20261005.md)及[历史股票剔除记录](06_清理_股票因子剔除_20261003.md)。

## 数据时点与缺失不能靠方便的替代

| 数据 | 必查事项 | 常见错误 |
|---|---|---|
| 财务 | 报告期、披露版本、日频生效日；同一报告前沿；严格单季和 TTM | 各表分别取最新值；缺季补零；修订回填历史 |
| 价格 | 公式实际使用的全部真实成交端点；停牌与跨年预热 | 填充价格被当作真实成交；忽略长期停牌左端点 |
| 分钟 | 按股票日核对手/股单位；棒数与网格；同日分段重置 | 只按一次日期切换单位；方向传播越过股票日边界 |
| 事件和网络 | 当时可得的历史映射；共同有效样本；月末冻结与下一日传播 | 最新行业或持仓回填；未知事件当作零；全样本 PCA |

缺失、未披露和真实经济零值分别处理。供应商没有保留的历史版本不能由现有代码凭空重建。五分钟端点代理不能称逐笔微观结构，现金差额也不能直接冒充受限现金。财务详细合同见 [R13 财务检查](05_经验_R13财务检查_20261006.md)。

## 统计审核保持同一方向 期限和样本

方向、主期限和公式在看结果前固定。G4 与 G7 必须在同一事前期限上判定，不能拼接不同期限的有利结果。补充控制必须真正进入联合回归，报告共同有效样本、两种内核、秩缺陷和逐年结果；输出里列出了控制名称并不证明它参与计算。

G3 在至少 100 股的可评价截面上计算，但仍完整报告稀疏性；G2 覆盖要求独立判定。C 通道的弱证据、放宽准入和弱增量标记如实保留。GC 描述通道须事前声明用途，不能作为失败预测因子的事后救援。

IC、控制后增量、独立样本外确认和账户盈利分别解释，不能互相替代。实测案例见 [R05 至 R08 复盘](05_经验_R05至R08复盘_20261005.md)和 [R13 主审阶段记录](05_经验_R13主审阶段_20261006.md)。

## 工程对拍检查有效值和初始化

正式验证核对完整键轴、float32 value、rank 与 NaN；全 NaN 相等不证明实现正确。预热是日历天，年度面板锚点和递推初始化不能随增量起点改变。真实输入截断与两阶段增量对拍通过后，再进行主审和生产对拍。

P007/P009/P011 的成交端点缺陷、P014 的 832 格浮点差异及网络 PRR 的 3 格差异均有具体根因。先定位公式、输入、面板范围和累积顺序，再决定修复版本；不能直接放宽误差掩盖差异。对应记录见 [R15 交付](04_研究记录_R15交付_20261008.md)。

## 生产恢复使用当前入口

默认 `python main.py` 补缺口和新增日期；强制重算使用 `rebuild`，全量中断后使用默认入口或 `rebuild --resume`。再次执行不带 `--resume` 的 `rebuild` 会重新强制计算。旧经验中“不要全量重算”的提醒是避免无必要的昂贵操作，不构成禁止用户明确要求的重建。

保留成功分区与断点，不手改状态制造完成，不删除锁文件绕过互斥。`list/status` 只读取注册与台账，不等于逐分区完整性审计。参数、退出码和恢复示例以[命令接口](01_生产_命令接口.md)为准，旧版接口仅用于追溯。

## 资源控制用当前测量

CPU、RSS、PSS、cgroup charged 和匿名内存分别说明。页缓存可能推高计费内存，单次低 RSS 不能用于承诺正式多进程峰值。分钟研究流式扫描和正式年度适配器是不同内存路径。

研究任务的总预算、重任务排队和资源护栏共同管理，不给每个执行者各分一份整机预算。生产调度与研究编排的默认并行数分别查当前配置，旧轮次的核数、槽位、内存上限和利用率不直接套用。未达到利用率目标如实记录，不为追求数字新增无意义任务。经验见[R13 复盘与模板](05_经验_R13复盘与模板_20261006.md)和[工程运维](05_经验_工程运维_20261006.md)。

## 入库后的证据按最新保留约定处理

2026-10-08 用户已明确允许：确认入库的因子只保留相关文档，移除研究证据与中间产物。移除前记录研究结论和清单，保留生产数据、实现及注册定义；未入库冻结方向另行保留。旧文档里的永久保留证据要求按这次授权更新理解。

## 开工和收尾检查

- 开工：确认授权和边界，读取现行生产说明与准入政策，核对现库与失败记录，冻结设计及参数，测量共享资源，再安排任务。
- 审核：核对源口径、真实时点、质量、声明方向、当前全库近邻、真实联合控制及正式工程一致性，明确通过范围和弱证据。
- 交付：核对生产注册、实际分区和生产对拍，写出因子数的统计口径、限制、失败与冻结方向，再按授权整理中间产物。

完整任务模板见[执行流程](02_研究_执行流程.md)，新研究的启动约定见[开工指南](02_研究_开工指南.md)。

## R16 GPU 模型与缓存身份经验（2026-10-08）

- 事前冻结目标期限、成熟信号槽、端点成交资格、训练/尺度规则、seed和训练预算。每月252成熟槽不足时整月缺测，不能向更老日期补槽。效果筛选与工程修复区分登记，工程source变化也须重验当前计算身份。
- 公共因子输出从2018开始，不代表600日Context预热自动具有2016/17父因子输出；私有历史桥应复用真实cutoff-bound Upstream、原父规格和phase/ST上下文，再与公共重叠逐格float32/NaN比较。
- NumPy object数组的原始bytes含对象指针，不能作为可持久复现的股票轴摘要。先明确转为固定Unicode文本，再散列dtype、shape和连续bytes；数值数组保持原canonical编码。v1虽全期/截断/增量输出精确，仍因cache lineage跨进程误拒绝被阻止准入。
- 必须用两个独立进程验证实际缓存读取，而非仅重复训练一致或模拟字典比较。第二进程对训练函数加失败保护、真实Engine再次调用，验证零训练调用及原模型/预测精确复用。修复版2018-01已通过该实际探针。
- CUDA应在worker懒初始化；持久worker复用也需检查。固定环境/确定性/线程与单GPU锁是计算合同，首轮多年补齐或全量重算按指定jobs1执行；记录实际allocator和进程内存，不将显存总容量等同于模型资源需求。
