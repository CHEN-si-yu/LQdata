## 可以复用的研究闭环

1. 从项目正式库、删除记录、失败试验和资源报告出发，确定尚未覆盖的经济含义。先问“描述什么、为什么可能有用、现有字段能否按真实时点表达”，再写算式。
2. 主审冻结 Idea、Family、Candidate：表达式、方向、期限、窗口、最少有效数、源单位、可得日、缺失规则、股票池、控制集、试验预算、政策版本及哈希。执行者据此实现，不能借结果调整设计。
3. 独立实现者用 Context/Engine/Store 合同完成代码，提供明确的纸笔参考例和边界例。主审读公式与实现，特别核对时间、单位、分母、停牌、零值和缺失。
4. 用不可变身份注册候选。在隔离命名空间完成全历史运行、正式全部期限评价、真实原始输入截止的截断复算，以及两阶段增量重放。每一步保存真实 RUN/E/V、源和计算身份及分区内容哈希。
5. 同时审查覆盖、非常数、统计方向、分年/剔除单年稳定性、与正式库及删除记录的结构关系、共同样本相关、稀疏/半离散来源和必要的联合解释。
6. 主审给每个候选明确裁决：准入、统计失败、结构失败、工程失败或有具体原因的终止。准入后走官方生命周期与完整发布；输出不完整时不能计数。保留不利结果及旧版本。

## 冻结模板

每个设计至少记录以下内容，可以用独立 JSON 定义与审查文档组合表达：

| 项 | 必须回答的问题 |
|---|---|
| 机制 | 现象和因果/描述边界是什么？文献提供的是机制、精确复制还是外部收益结果？ |
| 表达式 | 固定代数、窗口与最少有效数是什么？是否是旧式子的单调、反号或可重构改写？ |
| 方向与层级 | C 的预期收益方向是什么？GC 的原始尺度含义是什么？不得混用。 |
| 数据 | 声明全部字段、频率、单位、源表、输入父依赖和字段延迟。 |
| 时间 | T 时可见哪些记录？报告期和公告日如何处理？何时生效？ |
| 缺失 | NaN、真实零、停牌、非正分母、新版无效记录怎样处理？ |
| 样本 | 固定 2115 股票轴和 2018 起完整交易日轴；预热是日历天。 |
| 验证 | 纸笔例、边界例、实际截断、全量/增量、串并行及跨年标签成熟检查。 |
| 对照 | base8、冻结邻居、删除记录、已登记但未发布候选分别是什么？ |
| 裁决 | 当前政策及哈希、实际证据身份、不利结果、准入限制、发布证明。 |

“预注册候选”不能作为当前正式库的同义词。过去已登记但未运行的完全相同表达式，可以是有清晰出处的工程恢复；不能算独立新发现，也不能仅因旧登记存在就自动拒绝其首次有效发布。

## 财务数据：最容易出错的地方

财务原始收入/现金流多为累计 YTD。Q4 TTM 使用当年 Q4 累计值；Q1–Q3 的严格 TTM 为 `当前同季 YTD + 上年 Q4 YTD − 上年同季 YTD`。Q1 单季等于 Q1 YTD，Q2–Q4 单季等于同年当前 YTD 减紧邻前季 YTD。不能把“Q1 单季”错写成“Q1 TTM”，不能缺一个季度后压缩成最近四行。

先过滤 `comp_type=1/report_type=1`，再按整个源行选择版本。PIT 为有效 `ann_date/f_ann_date/end_date` 的最大值，要求有有效公告日。完全相同股票、报告期、PIT 的冲突按已冻结的物理最后整行处理，包括最后一行 NaN；无效最新版应清除旧状态。修订旧报告只能从修订可得日开始改变当前特征。源表缺少历史版本时不能声称已重建完整历史 PIT。

下一交易日映射只执行一次，报告期年龄按自然日且上限 550 天。同表比例使用同一报告前沿和时钟，不能拼接分子分母的不同可见期。来源负值、退款、转回和真零可保留；分母资格与零值真实性必须单独论证，不能把所有零改成 NaN，也不能把所有缺失填成零。

FI06 使用当前可见最新报告的季度 q，平均三个固定以前完整年度的同季收入/全年收入份额；不是当前日历季度的预测，也不是四个独立季度因子。所有 12 个历史 YTD 槽必须有限，季度差分允许有符号。四个份额的和为一的结构不能用于包装四个独立发现。

## 日频和分钟数据：窗口与单位

项目换手率按 `100*vol/float_share`，要核对成交量单位与股份单位；不能把 float_share 换成 free_share 后仍称同一算式。实际成交状态与价格状态分别读取。`ret_clean(1)` 当前成交门控不等于“两端连续交易”门控，复牌日有限收益可能包含停牌间隔价格变化。

PT01 要求完整月份和前月末真实成交锚点，坏的实际成交收益使整个月槽失效。PT05 使用固定 126 个已完成相邻源/响应对，至少 95 对，响应最晚为 T；不能跨缺失日期拼接相邻关系。PT06 是固定五个前年槽内“同月平均换手/全年平均换手”的直接比例再取算术均值，完整全年锚点不能包含当前未结束年份。v1 的 log 差在结果前由主审纠正并保留旧稿；合成测试需包括正比例缩放不变性。

分钟因子的局部 DataFrame 删除不等于释放上游读取器缓存。成功和异常路径都要在年度结束清理上游缓存，同时保留原有中间数组引用释放。模拟缓存协议测试只能说明引用/清理行为；真实 2026 压力测试、历史逐值一致和实际峰值测量完成前，不能宣称内存下降。

## 准入政策与解释边界

现行冻结 v3 允许 C 弱证据准入，保留全部较严 v2 数值结论而另写 v3 裁决。C 的覆盖最低 30% 日期各有至少 100 只有限值，活跃截面至少 90% 非常数；主要 h1/h5 中同一期限同时满足 G4 和 G7。G4 为正且 HAC 90% 下界大于零、至少五年正；G7 两种冻结表达方式系数和 t 都正，最大 t≥1.30、最小 t≥0.25，两者至少四年正且较强者至少五年正。弱证据、弱增量、近年不稳定要明确标记。不得为通过而反号、更换窗口、选择控制或改期限。

GC 是预先定义的市场结构或会计描述，不要求强行解释为未来收益预测。它仍须真实工程验证、非空/非常数、源含义和结构审核。相关≥0.98 拒绝，0.95–0.98 需人工判断，活跃截面至少 95% 非常数。失败的 C 不能事后改成 GC 来凑数量。

评价中的 RankIC 已是 declared 方向。回归、分层、正交与稳定性报告都保存 raw/declared 双列，`higher_is_better=false` 的方向转换不能做两次或漏掉。正式标签为 T+1 后复权开盘买、T+1+h 开盘卖，两端真实成交，未成熟保持 NaN；未来成交掩码只能用于离线评价。

## 重复性审核的技巧

先做代数和排序结构检查，再做统计相关。单调函数、反号、阈值事件、分子分母或互补份额重构，都可能只是在旧信息上换尺度。FIP 的表达式存在 `-PRET*ID = abs(PRET)*(pct_pos-pct_neg)`，因此成分重构必须明确记录。

相关应把双方 raw 值在同日共同有限样本上重新做平均并列秩，至少 100 对；不能直接用各自在不同样本上存储的 rank 比较。半离散和零多的值不得随机拆并列。固定 208 基准工具锁定整个发布清单 SHA、唯一对象集和 2115 轴，逐分区读取前后核对 SHA，并持官方共享发布锁。

低两两相关不足以证明新增信息。H7 在一份相同共同样本上保留所有冻结 base8 与正式会计邻居，用原值和平均并列秩两种视图检查联合解释，数值尺度用 ddof=0 标准化，固定 `lstsq rcond=1e-12`。秩亏、病态、样本不足要报告，不能删列“救”结果。自己的分子/分母总能重构自己的比例，这是分解恒等式，不是“已被正式库重构”的证据；来源操作数诊断不得混成正式控制。

## 并行、资源与失败教训

年度 worker 用独立 spawn 进程且只处理一个年块，父进程负责父依赖年度屏障、ST 阶段状态和每个 spec 的最后封存。原始输入截止是验证阶段的全局截止，年度输出截止另存，尤其标签不能因年块结束提前截掉跨年未来端点。每阶段/每年衍生缓存隔离；不能用“最终值 NaN”冒充真实原始读取截断。

动态候选模块在父进程能导入，不代表 spawn 子进程能导入。初次 338 测试中三个沙箱模块回归失败；后来增加候选构造器源路径、源 SHA 与定义身份的冻结加载支持，全部 338 测试通过（216.018 秒）。子进程必须使用项目基准 Catalog，不能错误使用输出沙箱 Catalog。

当前四个日频实际全历史计算耗时 434.9、435.7、454.2、468.0 秒；相近旧串行约 1157–1177 秒，观察约 2.7 倍加速，混合并发和 I/O 条件不同，不能当受控基准。样本区间平均 12.231 核，32 核配额利用约 38.22%，峰值 cgroup charged 约 40.4 GB。资源预留按任务实际档位：price 4 年度 worker/9 GB，finance 3/12 GB，minute 1/18 GB，audit 1/2.8 GB；总预留 36 GB，charged guard 54 GB，进程地址空间 24 GiB，数值线程 1。

只看 CPU 核数并增加并发会把缓存、地址空间或 I/O 推到瓶颈。RSS 求和会重复计算共享页，主要看 cgroup charged 和 PSS。不要在分配锁内等待，避免所有排队者串行堵塞；旧调度器与新槽位合同也要区分。inode 要单独监测，重复正式标签和全财务衍生缓存能先耗尽 inode，即使磁盘字节仍充足。清理只能针对确认可重建、已封存且不被活跃任务引用的缓存；候选值、标签、证据、日志、失败记录、源和 manifest 都保留。

生产恢复时发现：以总体覆盖裁剪缺失输出可能误删未完成的旧对象。修复后只用本次协调器明确完成的因子及年度身份做裁剪；老进度没有该身份就不能裁剪任何历史因子。不能手删未完成生产日记或改批准哈希来绕过守卫。

## 文献如何使用

资源报告、原论文和开源公式库首先是机制与实现线索，不能直接变成当地收益证据。月度销售季节性和注意力机制可参考作者的 [销售季节性研究](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=3174181)；FI06 只借用经营季节性含义，未移植美国组合收益或短日频方向。[隔夜注意力研究](https://www.cambridge.org/core/journals/journal-of-financial-and-quantitative-analysis/article/abs/paying-attention-overnight-returns-and-the-hidden-cost-of-buying-at-the-open/F9AAD159B512C651F09D5D52011D88E0)提供隔夜价格与日内反转背景，不能证明本项目 60 日响应 beta 的预测能力。

同一研究方向只保留有限的事前变体，避免对窗口、期限、符号和控制集合做网格搜索。旧失败结果可以读、可以总结；需要限制的是看自己结果之后重写冻结假设，不能把所有历史经验都禁读。
