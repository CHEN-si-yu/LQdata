## 本轮编排

- 主 Agent：主审/裁判。负责设计审阅、初筛裁决、正式 run/evaluate/verify、晋级、生产物化、
  对拍、台账与文档；不采信子 Agent 的口头有效性结论。
- 子 Agent 席位（按需逐步拉起）：
  1. `seat_fin_bs`：资产负债表构成、杠杆与流动性结构（GC 为主）。
  2. `seat_fin_is_cf`：利润表/现金流量表结构、应计与盈利质量（GC/C）。
  3. `seat_price`：日频价格/成交量分布、路径、流动性与尾部（C 为主）。
  4. `seat_flow_event`：资金流、两融、涨跌停、业绩预告、股东/质押/筹码、龙虎榜（C/GC）。
  5. `seat_intraday`：5 分钟日内结构、时段分配与到达时序（C/GC）。
  6. `seat_cross`：截面/网络/日历/市场状态条件（C/GC）。
- 工具：`artifacts/research/round17_20261018/` 下的 `r17_register_family.py`、
  `build_family_fullaxis.py`、`r17_screen_batch.py`、`r17_g5_batch.py`，以及继承的
  bounded/screen/formal/chief_release/production_compare。全轴构建已用 R15 CF01
  逐字节对拍验证。
- 流水线：设计冻结 → 登记真实 candidate_id → 无标签全轴构建 → v4/v4.1 初筛 →
  当前 260 库 G5 → 主审选批 → 正式 run → 初筛/正式逐格对拍 → 真实截断+两阶段增量 →
  主审裁决 → `qualified→shadow→production` → `main.py run` 物化 → 生产逐值/字节对拍 →
  库缓存刷新 → 下一批。

## 设计边界

- 不重复现库 260 个股票因子的构念；同机制换窗、翻号、单调变换、代数互补第三腿不计新因子。
- 财务严格 TTM/同报表前沿/公告可得日；价格收益端点真实成交；5 分钟核验单位与网格；
  事件与不定期披露不得用最新映射回填历史。
- GC 必须有明确描述用途且 G5<0.98；C 必须事前声明 h1/h5 方向并通过 v4 G4/G7。
- 所有失败与修复留痕；不把“计算完成”或“数量达标”当作有效因子证明。
